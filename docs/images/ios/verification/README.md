All screens use explicit offline fixtures. These captures do not verify live account or model integration.

The self-contained gallery is attached to GUL-199; the PNGs below can be viewed directly in GitHub.
The PNG files are copied unchanged from xcresult attachment exports. Later input exports replace earlier
captures with the same normalized name. The index identifies the source test; it does not assert test results.
