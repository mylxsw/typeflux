Scrolling capture starts in manual mode. Scroll down or right inside the selected region; the first accepted movement chooses the axis for that capture. Reverse scrolling does not add duplicate content. Small movements before the axis is chosen are ignored, and incoming frames are sampled after a 250 ms quiet interval, with a 250 ms bounded sampling interval to retain overlap during continuous gestures.

Click **Auto** or press Space to start automatic scrolling. It scrolls vertically before a manual direction has been chosen, or continues horizontally after a horizontal manual capture. Mouse input takes over again. Accessibility is checked only when Auto is requested; manual capture works without it. Enter finishes and opens the existing long-image editor. Escape cancels; Delete removes the newest segment.

The PNG files in this directory are native AppKit renders of the manual and automatic capture bars, generated by `ScrollCaptureUITests.testManualAndAutomaticBarsRenderForReview` with `TYPEFLUX_SCROLL_REVIEW_DIR` pointing to this directory. They use synthetic dimensions and do not contain screen contents.
