The shared media preview helper now runs Apple Vision only when the selected hit carries `image-ocr` evidence from the current file version. It matches the stored passage against recognized text and asks Vision for substring geometry. Yellow regions are composited into the same EXIF-oriented, aspect-fit raster used for display, so subsequent SwiftUI scaling moves the image and highlight together. Other visual hits do not request text location. A missing passage, invalid/missing region or stale index evidence renders the current image with an explicit localized text-location fallback. Preview metadata now carries the existing device/inode/size/nanosecond mtime/ctime identity. The loader/controller retain cancellation, deadline, lifecycle ownership and permission-epoch guards.
