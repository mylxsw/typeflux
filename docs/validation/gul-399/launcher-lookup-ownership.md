# Launcher synchronous lookup ownership

The immediate icon path now checks its original global/private-file generation and caller cancellation after the synchronous lookup and after rasterization. A nested lookup that has already completed the same key is reused rather than overwritten by the older callback. Completed cache hits remain independent of native health and do not start new lookup work, including for a canceled caller.

Prefetch checks original source generations, cancellation and the current namespace's wanted set after each lookup and before admitting a Task. A retired lookup's nil is not interpreted as permission to start native work under a newer owner. Compatible nested requests with the same wanted keys still coalesce; a replacement wanted set retires old admission. Application metadata survives private-file clearing, while a file query is retired even when its target is an application bundle.

Returned Task handles retain work accepted or observed for the current ordered keys even if a callback removes it from the dictionary. Existing task UUIDs deduplicate handles; these are collection receipts, not counts of newly started jobs. Prior receipts remain necessary for earlier tasks pruned from unrelated previous wanted keys. No new token, dispatcher, aggregator, queue, pool, grant, module handle or DI layer was added. Native batch authorization and physical worker collection are unchanged.

## Limits

The default systemIcon/NSWorkspace implementation remains a synchronous host boundary, not crash-contained. Tests never resolve actual icons/apps/files or execute NSWorkspace/QuickLook, codec/encoding/helper/Vision, HTTP/provider/paid work, clipboard (including named), SystemClipboardContentActions, ConversationModel/AskTestFixture, Downloads/home/apps, windows/rendering, capture/audio/TCC, signing/hardware or unrelated document/resource tests. Selected custom loader-only cache fixtures may use the default lookup function reference but never invoke it; all prefetch/immediate fixtures inject nil/private images.

Scope is the described synchronous callback/caller-Task/source-generation boundaries, not arbitrary Published/Combine/AppKit/custom-clock reentrancy, all UI epochs or a filesystem/settings/account permission transaction. Already-entered effects cannot be rolled back. Native availability is not source/account/copy/export consent. No health-triggered prepare/probe/warmup/rebuild/replay/download/write/export/delete or producer retry was added; original budgets, grants, cancellation and actual FD/private-copy/child-host collection remain. Host/native crash, OOM and power loss guarantees remain outside this proof. Artifact card save-dialog local error/export lifecycle remains separate. No presentation layout/ABI/entry/package changes, so no screenshot or copied helper probe.
