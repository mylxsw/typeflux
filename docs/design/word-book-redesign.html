单词本改版 · dict 关键字

GUL-237 第三版设计稿。两件事：① 启动器新增 dict（及 词典）关键字，在「翻译」一组里，直接打开单词本并在里面查词；② 单词本窗口按随便问工作区的 Liquid Glass 风格重做：悬浮玻璃侧栏、顶部玻璃查词栏、三栏布局、卡片式详情、底部玻璃操作条。下面三块都能操作，并共用同一份数据：在 ① 按 ↩，会在 ③ 里完成查词。

键盘：点一下单词本窗口再试 ⌘L 查词 · ↑↓ 选择 · ⌘S 收藏 · ⌫ 删除 · ⌘F 过滤 · esc（Ctrl 代替 ⌘ 也行）

① 启动器：dict 打开单词本

单词本
  • 关键字：dict、词典，放在启动器关键字设置的「翻译」一组里（见 ②），可改名、可关闭，与 fy 一样自定义。
  • 只输入 dict：第一行「打开单词本 ↩」，下面是最近查过的词（与 fy 留空一致）；↩ 打开窗口，↓ 选一个词再 ↩ 直接打开到这个词。
  • dict + 词：本机先给一行简短译文做预览（不发送任何内容）；↩ 打开单词本并在窗口里查这个词——AI 单词卡在窗口里生成，自动记入单词本。单词本里已有卡片的词，预览直接显示「来自单词本」。
  • 和 fy 的区别：fy 是“查完就走”（复制 / 插入）；dict 是“进单词本细看”。两者共用同一个单词本。
  • 有选中文字且只输入 dict 时，↩ 用选中的词在单词本里查（多行或句子则只打开窗口）。

  • 窗口：与随便问工作区同一套语言——隐藏标题栏、红绿灯嵌在悬浮玻璃侧栏上，环境光晕随强调色；macOS 26 用系统 Liquid Glass，13–15 用 HUD 毛玻璃，「减少透明度」时退回不透明（复用 AskGlass）。
  • 顶部查词栏（核心）：随时 ⌘L 输入一个词。打字时本机给出一行预览（不出本机）；↩ 用 AI 生成单词卡，结果直接显示在右侧并记入「今天」；⇥ 或点方向切换语言。已查过的词直接打开存下的卡，不再请求模型。
  • 侧栏：资料库（全部 / 收藏 / 今天 / 本周）+ 语言方向；底部是连续查词天数与本周柱状条，给一点点成就感；导出与记录设置收在这里，不占主界面。
  • 列表：大字号词头 + 音标 + 一行释义；悬停出现 ☆，查过多次显示 ×N；按天分组；顶部可过滤与排序。
  • 详情：大号词头，音标胶囊里直接朗读（英 / 美音）；收藏是醒目的星形按钮；释义按词性分组，点一条即复制；例句可朗读；近义词与词形是可点的胶囊——点了就在单词本里查它，方便顺藤摸瓜。
  • 底部玻璃操作条：复制释义 · 朗读 · 问 AI（带着单词卡开一段随便问）· 重新生成 · 删除，常用操作一处找到。
  • 状态：生成中骨架屏；新词标「新词 · 已记入」；查过的标「第 N 次查」；空状态给出 3 条上手提示；删除、复制等用底部玻璃提示，删除可撤销。
  • 键盘优先：⌘L 查词、⌘F 过滤、↑↓ 选择、⌘S 收藏、⌘C 复制释义（焦点不在输入框时）、⌫ 删除、esc 依次清空输入 / 关闭窗口。
