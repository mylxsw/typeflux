# Agent 配置页重新设计

> **GUL-227 更新：** 页签已改为左侧二级列表（主从布局），启动器功能移到一级导航「启动器」。可交互设计稿：`docs/design/agent-settings-panes.html`。下文第 1–2 节记录的是 GUL-207 的版本，最新结构见文末「GUL-227：二级列表与统一模板」。

> 状态：已按本方案实现（GUL-207）。可交互设计稿：`docs/design/agent-settings.html`（浏览器直接打开，右上角可切换深浅色、开关设计标注）。截图在 `docs/design/agent-settings/`；现状截图见 GUL-207。

## 1. 现状问题

当前页面（`SettingsView.agentPage` + `AskToolsSettingsView` + `MemoryNotesEditorView`）用一个 5 段的分段控件切换：通用 / 工具 / MCP / 技能 / 记忆。主要问题：

1. **看不出“随便问”现在能做什么。** 能力分散在 5 个页签里，没有一个地方能看到整体状态；配置没完成（例如 Cloudflare 缺账户 ID）时也没有提示。
2. **分组不对。** 「通用」里只有“对话存储”和“本机网页搜索”两项，而联网搜索是工具。「工具」页签里却没有联网搜索。
3. **说明文字长、术语多。** 存储说明有 100 多字；记忆页脚注里有“源记忆 / 快照 / 注入 / 衍生文本”这类开发者用语；Cloudflare 的帮助文字堆在 6 个输入框下面。
4. **大部分页签几乎是空的。** MCP、技能、记忆各只有一个列表，下面一大片空白；MCP 空状态只有一行“尚未配置”。
5. **控件风格不统一。** 同一个页面里混用了 SecureField 自绘框、`.roundedBorder` 文本框、原生 Picker 和自绘菜单；记忆页的搜索框是一个光秃秃的 TextField；“测试连接”按钮在没填完时直接置灰，不说缺什么。
6. **重要信息藏起来了。** 技能的来源、版本、声明权限只在悬停提示里；MCP 服务器连上之后有几个工具、是否连接成功，在列表里看不到。
7. **已有能力完全不可见。** `computer` / `browser` 工具已经存在（`AskLocalTools+Automation.swift`），但设置页里没有任何入口说明它需要什么权限。

## 2. 新的信息架构

页签从 5 个减为 4 个：

| 页签 | 内容 | 来自原来的 |
|------|------|-----------|
| **概览**（默认） | 能力状态汇总；新对话默认存储位置；6 张能力卡片 | 通用 · 对话存储 |
| **内置工具** | 联网搜索、文件访问、代码执行、操作电脑与浏览器 | 通用 · 联网 + 工具 |
| **扩展** | 技能 / MCP 服务器（二级分段切换） | 技能 + MCP |
| **记忆** | 笔记列表、搜索、添加、修改、删除 | 记忆 |

原则：

- **先说结论，再给设置。** 每个能力都有一个状态标签（已开启 / 未开启 / 待完成配置 / 缺少系统权限），概览把需要处理的项目汇总，并提供“去处理”跳转。
- **按需展开。** 只有选了某个服务商才显示它的字段；不常用的字段（BYOK 别名）收进“高级选项”。
- **规则用标签，不用段落。** 安全规则（无网络、写入要确认……）拆成短标签。
- **可撤销优于确认弹窗。** 移除文件夹、删除笔记都改成“直接执行 + 5 秒内可撤销”；只有删除 MCP 服务器、移除技能这类会删文件或配置的操作保留确认。

## 3. 各页设计

### 3.1 概览

- **汇总条**：“随便问 现在可以使用 N 项能力”，下面列出需要处理的项目，右侧“去处理”跳到第一项并高亮。
- **新对话默认保存在**：两张并排的单选卡片（云端同步 / 仅存本机），每张卡用 ✓ / – 清单写清差异，代替原来的长段落和下拉框。底部一行提示：已开始的对话不能改；未登录时只能存本机。
- **能力卡片**（3 列）：联网搜索、文件访问、代码执行、操作电脑与浏览器、技能、MCP 服务器。每张卡有一句说明和状态标签，点击跳到对应设置位置。
- 状态联动：默认“仅存本机”且联网搜索关闭时，联网搜索显示“本机对话无法联网”警告。

### 3.2 内置工具

- **联网搜索**
  - 标题旁标“仅本机对话”，副标题说明云端对话由 Typeflux Cloud 提供、无需配置——原页面没讲清楚这一点。
  - 服务商用分段控件：关闭 / Tavily / Brave Search / Cloudflare。
  - Tavily、Brave：一个密钥输入框 + “获取密钥”链接。
  - Cloudflare：API Token、账户 ID、Gateway ID 标为必填，再加搜索引擎下拉框；BYOK 别名放在“高级选项”里。
  - 测试连接：没填完时按钮旁直接写出“还需填写：账户 ID、…”；结果在原位显示为绿色或红色提示条（文案沿用现有 `ask.settings.search.cloudflare.*`）。
- **文件访问**：文件夹列表（名称 + 完整路径）、移除（可撤销）、“添加文件夹…”；三个规则标签：只能访问列表里的文件夹 / 读取可在对话内一次性允许 / 写入每次都要确认。
- **代码执行**：开关；打开时显示三个标签：无网络 / 不能访问个人目录 / 每次运行前确认。
- **操作电脑与浏览器（新增展示）**：显示“辅助功能”“屏幕录制”两项系统权限的授权状态；未授权时显示“打开系统设置”。这里不增加新开关，只把已有能力和它需要的权限讲清楚。

### 3.3 扩展

顶部用分段控件切换“技能 N | MCP 服务器 N”，右侧放当前分段的主操作。

**技能**

- 工具栏：搜索框 + 全部 / 已启用 / 已停用 筛选。
- 列表行：名称 + 来源标签（内置 / GitHub / 本地）+ 一行描述 + 开关。
- 点击行打开**右侧详情抽屉**：启用开关、完整描述、来源（仓库、分支 · 提交、路径）、声明权限标签（注明“声明不授予权限”）；底部放恢复上一版本、在访达中显示、移除。内置技能不显示移除。
- 安装弹窗：输入链接后立即解析出“将从 仓库 · 分支 · 路径 安装”；链接不合法当场提示；警告文案保留。

**MCP 服务器**

- 空状态：说明 MCP 是什么并举例，给出“添加服务器”和“从 JSON 导入”两个入口，并说明支持 stdio 和 HTTP。
- 列表行：名称 + 连接方式标签 + 命令或 URL + **状态点**（已连接 · N 个工具 / 连接失败 / 未测试 / 已停用）+ 启用开关 + “…”菜单（测试连接、查看工具列表、编辑、复制、删除）。连接失败的原因显示在行下方。
- 添加 / 编辑弹窗：
  - 连接方式用“本地命令 / 远程 HTTP”分段控件。
  - 参数每行一个。
  - 环境变量和请求头改为**键值行编辑**（代替 `KEY=VALUE` 多行文本），值默认用密码框显示。
  - “启用”和“启动时自动连接”两个开关各配一句说明。
  - 测试结果直接列出工具名。
  - 名称、命令或 URL 填好之前，“保存”和“测试”不可点。
- **从 JSON 导入（新功能）**：粘贴 Claude Desktop / Cursor 格式的 `mcpServers` 配置，预览将要添加的服务器后批量导入。

### 3.4 记忆

- 顶部三张说明卡用白话讲清规则：会用在新对话里 / 保存前先问你 / 删除即停止使用（已有回复不变）。这三张卡替代 `memory.boundaries` 那段说明。
- 工具栏：搜索框、笔记数量、“添加笔记”。
- 列表行：笔记全文 + 一行元信息（“你让它记住的 / 你修改过 · 日期 · 一直保留 / 保留到 某日”）+ 修改、删除。
- 修改改为**行内编辑**：文本框 + 保留期限下拉框 + 取消 / 保存，不再弹出 sheet。
- 删除后 5 秒内可撤销。
- 空状态给出示例（称呼、常用语言、工作习惯）。
- 底部提示：删除笔记不会删除对话历史。

## 5. 实现时的取舍

方案确认后按原设计实现，几个待确认项的处理如下：

1. **操作电脑与浏览器**：只展示辅助功能、屏幕录制两项权限的状态和授权入口，不加总开关。
2. **MCP 从 JSON 导入**：支持 `mcpServers`（Claude Desktop、Cursor）、`servers`（VS Code）和不带外层键的写法。名称重复时自动加序号，例如 `linear 2`。缺少命令和 URL 的条目会被跳过，并在预览里列出。
3. **手动添加笔记**：允许，和对话里保存的笔记走同一个 `AskMemoryNoteStore.add`，同样受 50 条、300 字的上限约束。
4. **页签名称**：沿用设计稿里的“概览 / 内置工具 / 扩展 / 记忆”。
5. **Recent / Soul**：本次不在记忆页加入口。
6. **删除笔记后撤销**：删除会立即生效，保证内容马上不再被使用。撤销时用原文和原保留期限重新保存一条笔记。
7. **详情抽屉**：应用最低支持 macOS 13，用不了 `inspector`，技能详情改用 sheet 展示。

## GUL-227：二级列表与统一模板

GUL-207 之后「内置工具」页签又陆续加入了启动器计算器、应用搜索、关键字和工作流，一页里有 7 类设置，其中 4 类与 Agent 无关；「扩展」里还有一层技能 / MCP 分段。本次调整：

| 位置 | 内容 | 实现 |
|------|------|------|
| Agent · 概览 | 能力汇总、新对话默认存储、「需要处理」清单（取代 6 张能力卡） | `AskToolsSettingsView+Overview.swift` |
| Agent · 能力 | 联网搜索 / 文件访问 / 代码执行 / 操作电脑与浏览器，各一页 | `AskToolsSettingsView+Tools.swift` |
| Agent · 扩展 | 技能 / MCP 服务器，各一页 | `+Skills.swift`、`SettingsView.agentPage` |
| Agent · 个性化 | 记忆 | `MemoryNotesEditorView` |
| 启动器（一级导航） | 内置功能（计算器、应用搜索）/ 启动器关键字 / 启动器工作流 | `LauncherSettingsView` |

- **二级列表**：`SettingsPaneLayout` 左侧分组列表 + 右侧详情；每项显示状态点和一行状态（来自 `AgentCapabilityStatus`，MCP 状态直接取服务器列表）。内容宽度小于 720pt 时折叠成详情上方的菜单。
- **统一模板**：每页都是 `AgentPaneHeader`（图标、标题、一句话说明、状态徽章 / 总开关）→ 设置卡片 → `AgentRulesCard`（安全规则 / 使用规则）→ 脚注。
- **渐进展开**：联网搜索由页头开关控制，关闭时只显示一条说明；打开时有 Cloudflare 账户则选 Cloudflare，否则选 Tavily。
- 设置项和存储键均未改变。
