# 圆环设置 v3（Ring Studio）设计方案

> 状态：待确认（GUL-470）。可交互设计稿：`docs/design/ring-studio.html`（顶栏可切换场景：默认 / 空圆环 / 已满 / 有失效项，以及浅色 / 深色）。截图在 `docs/design/ring-studio/`。原圆环交互见 `ring.md`，本方案只改「设置 → 圆环」页，运行时圆环和 `RingConfiguration` 存储格式不变。

## 0. 一页结论

**圆环本身就是编辑器。**

- 在圆环上点 ⊕，就在那个位置插入。
- 右侧面板可以直接浏览、搜索，点一下就加进去。悬停某一项，圆环里马上预览。
- 改名、换图标、调位置都立即生效，删除可以撤销。
- 没有弹窗，也没有「保存」按钮。

| 现在 | v3 |
|---|---|
| 「添加操作」只能加到末尾 | 圆环外沿每两个操作之间有一个 ⊕，点哪里就插在哪里 |
| 模态 Sheet：类型下拉 → 目标下拉 → 名称 → 图标 → 添加 | 右侧操作库：全局搜索、推荐、8 个类型卡片，点一下就加入 |
| 看不到加进去会是什么样 | 悬停或用方向键选中一项，圆环里的虚线空位实时显示它的图标和名字 |
| 编辑也要开 Sheet，改完点「保存」 | 编辑面板不是弹窗，改动直接写进圆环 |
| 排序只能在列表里拖，或用菜单「上移 / 下移」 | 在圆环上直接拖图标；也可以用「逆 / 顺时针」按钮或 ⌥← / ⌥→ |
| 删除、恢复默认要先确认 | 直接执行，toast 提供「撤销」，也可以按 ⌘Z |
| 满 8 个时，原因藏在 tooltip 里 | ⊕ 消失；左上角显示「已满 8 / 8」；列表末尾说明为什么满、接下来怎么做 |

## 1. 现状问题

| # | 问题 | 代码位置 |
|---|---|---|
| P1 | 新操作只能追加到末尾，要放到某个方向还得再挪 | `RingSettingsView.actionsSection` 的「添加操作」→ `RingSettingsModel.save` |
| P2 | 添加要先懂分类：选项藏在两层下拉里，看不到全貌，也看不到效果 | `RingActionEditorSheet`（`TFPopUpButton` + `TFRichPicker`） |
| P3 | 不能跨类型搜索，例如不知道「截图」算「功能」还是「系统操作」 | 每种类型各用一个 picker |
| P4 | 预览只能看不能改；列表和圆环重复展示同样的内容，「第几个对应哪个方向」只能自己数 | `RingPreviewView` 只响应点击，点击后打开 Sheet |
| P5 | 编辑要开模态窗口，点「保存」之前看不到效果 | 同 P2 |
| P6 | 删除和恢复默认都要先确认，打断操作节奏 | `.alert(ring.delete.title)`、`.alert(ring.reset.title)` |
| P7 | 满 8 个后，按钮只是变灰 | `.help(ring.actions.full)` |

## 2. 设计原则

1. **直接操作**：位置就是圆环上的方向，不用再换算成列表里的第几行。
2. **先看见，再决定**：可选项平铺展示，悬停即预览。
3. **一次点击完成添加**：点一下就加入，随后自动打开这一项的编辑面板，改不改都行。
4. **无模态，即时生效**：和 macOS 系统设置一致。
5. **出错能撤回**：删除、更换、添加、排序、恢复默认都进入撤销栈，最多保留 20 步。
6. **键盘也能完成**：每个鼠标操作都有对应的按键。

## 3. 布局

「操作」卡片改成左右两栏的 Ring Studio，高 520pt：

- **左侧画布（440pt）**：深色壁纸底，圆环外观和运行时一致，样式和中心文字也实时同步。
  - 左上角：容量胶囊。
  - 右上角：「试一试」。
  - 底部：随当前状态变化的操作提示。
  - 每个扇区内缘标出序号，就是轻按快捷键后可以按的数字键。
- **右侧检查器**，有三种状态：

| 状态 | 怎么进入 | 显示什么 |
|---|---|---|
| 总览 | 默认；Esc；点画布空白处 | 从正上方开始顺时针列出操作：序号、图标、名称、说明、方向。可以拖动排序。末尾是「添加操作」，加到最后 |
| 操作库 | 点 ⊕、「添加操作」或编辑面板里的「更换…」 | 标题写明插入位置，例如「添加到第 4 个位置 · 圆环的右下方 · 轻按后按 4」。下面是搜索框、推荐和类型卡片。点进某个类型后显示分组列表；快捷键、网址、文件夹三类是直接填写的表单 |
| 编辑 | 点圆环上的图标或列表行；添加完成后自动进入 | 名称（就地编辑，清空即恢复默认）、动作（「更换…」，参数直接在面板里改）、图标网格、位置（方向示意 + 逆 / 顺时针）、复制、删除 |

「快捷键」和「外观」两块保持现状。原来的「练习」改为画布上的「试一试」：在画布里划动只显示将执行什么，不会真的执行。

## 4. 关键流程

### 4.1 在指定位置添加

1. 鼠标移到画布上，⊕ 变亮。悬停在某个 ⊕ 上，它会放大并变成蓝色，tooltip 显示「在这里添加（第 4 个 · 右下方）」。
2. 点击后，圆环在这个位置让出一个蓝色虚线空位，其余扇区重新均分，序号随之更新。右侧切到操作库，搜索框获得焦点。
3. 悬停某一项，或用 ↑ / ↓ 选中，空位立即显示它的图标和名称。
4. 点击或按 ↩ 加入：空位变成实心，右侧进入编辑面板，toast 提示「已添加到圆环的右下方 · 撤销」。
5. 按 Esc、点 ✕ 或点画布空白处取消，空位收回。

### 4.2 操作库

- **搜索**：覆盖功能、关键词、系统、快捷指令、应用、文件夹和常用组合键，结果按类型分组，命中的文字高亮。
  - 输入像网址的文本时，第一条是「打开网址 …」。
  - 输入以 `~` 或 `/` 开头的路径时，第一条是「打开文件夹 …」。
- **未搜索时**：先是「推荐」，列出尚未加入的高频项，最多 4 个；下面是 8 张类型卡片，写明各自作用和条目数量。
- **已在圆环里的项**：显示「已添加」，但仍可再加一次。
- **三类表单**：
  - 快捷键：大号录制区，下面附常用组合键。
  - 网址：输入框加实时校验，只接受 http / https，与 `RingActionExecutor` 一致。
  - 文件夹：常用文件夹列表，加「选择文件夹…」（`NSOpenPanel`）。
- **替换模式**（从「更换…」进入）：标题为「更换「X」」，位置不变。名称和图标如果没有自定义过，会跟着新动作更新。

### 4.3 编辑与排序

- 名称、图标和参数都实时写回，圆环同步变化。
- 拖动圆环上的图标：超过 6pt 才算拖动，否则视为点击。拖动过程中其他扇区实时让位，松手后落定，toast 显示「已移到右侧 · 撤销」。
- 拖回原位不算改动，不会进入撤销栈。

## 5. 键盘

| 按键（焦点在画布上时） | 作用 |
|---|---|
| ← / → 或 ↑ / ↓ | 逆时针 / 顺时针选中上一个 / 下一个 |
| ⌥← / ⌥→ | 把选中项移动一格 |
| 1–8 | 选中对应序号的操作 |
| + | 在选中项之后插入；没有选中项时加到最后 |
| ↩ | 编辑选中项，焦点放在名称上 |
| Delete | 删除选中项，可撤销 |
| Esc | 取消添加，或退出编辑 |
| ⌘Z | 撤销 |
| 操作库中 ↑ / ↓ / ↩ / Esc | 移动选择（圆环同步预览）/ 添加 / 依次清空搜索、返回上一级、关闭 |

## 6. 边界情况

| 情况 | 处理 |
|---|---|
| 0 个操作 | 画布显示虚线空圆环，中心是蓝色大 ⊕「添加第一个操作」；右侧直接打开操作库。第一个操作占满整圈 |
| 1 个操作 | 只有一个插入点，在正下方 |
| 已满 8 个 | ⊕ 全部隐藏；左上角显示「已满 8 / 8」；总览末尾说明扇区太窄会难以划中，可以先删除一个或用「更换」；「复制」按钮禁用；按 + 时提示已满 |
| 目标失效（应用已卸载、关键词被删除、网址无效） | 扇区图标变暗并带黄点；总览行带黄点；编辑面板顶部黄条说明原因，并提供「更换…」 |
| 名称过长 | 圆环标签最多两行并截断（与运行时一致）；列表单行截断；名称最多 24 个字 |
| 圆环开关关闭 | 整页降到 45% 不透明度，不能操作（现有行为） |
| 正在录制快捷键 | 其他快捷键暂不响应，Esc 取消录制 |

## 7. 实现映射

| 模块 | 改动 |
|---|---|
| `RingConfiguration` / `RingAction` | 不变，无需迁移 |
| `RingSettingsModel` | 新增 `insert(_:at:)`、`replaceKind(of:with:title:symbol:)`、`move(_:to:)`，以及有界撤销栈 `undo()`（20 步）。`save` 只用于更新已有项 |
| `RingPreviewView` → `RingStudioCanvas` | 加入插入点（⊕）、占位扇区、悬停预览、选中描边、序号、拖动排序和试用模式；命中判断复用现有角度计算。⊕ 和扇区都要提供无障碍元素 |
| 新增 `RingInspector` | `enum RingInspectorState { case overview, library(RingLibraryTarget), edit(UUID) }`；`RingLibraryTarget` 为 `.insert(at:)` 或 `.replace(UUID)` |
| 新增 `RingActionLibrary` | 把 `RingFeature`、`RingSystemAction`、关键词（`HotkeySettingsModel.options`）、`PersonaAppDiscovery` 应用、快捷指令（`/usr/bin/shortcuts list`，失败时退回手动输入）和常用文件夹聚合成可搜索的条目 |
| 删除 | `RingActionEditorSheet`、删除确认 alert、恢复默认确认 alert |
| 测试 | `RingSettingsModelTests`：insert / replace / move / undo，以及上限和越界。新增 `RingActionLibraryTests`：搜索、网址和路径识别、「已添加」标记。`RingSettingsPresentationTests`：方向名和序号 |
