# 剪贴板面板：来源应用图标 + 媒体内联预览

> 状态：已确认并实现（GUL-298）。可交互设计稿：`docs/design/clipboard-source-media.html`（浏览器直接打开，可切换「优化后 / 当前」和深浅色）。

## 1. 问题

| 问题 | 原因 |
|------|------|
| 条目左侧不是来源应用的图标 | `ClipboardMonitor` 已经记录了复制时前台应用的 bundle ID（`clipboard_items.source_bundle_id`），但 `ClipboardFeed.entry(for:)` 只把应用名传给了 `ClipboardEntry`，所以 `ClipboardEntryTile` 只能按内容类型画图标 |
| 图片、视频、音频显示成“图片”“视频”等文字 | 截图这类图片没有文件名，标题就回退成 `clipboard.entry.image`。图片和视频只有 32px 的小缩略图，音频只有一个 ♪，预览要选中后才展开 |

## 2. 方案

**左侧图标**
- 显示来源应用的图标：`ClipboardEntry.sourceBundleID` → `ClipboardAppIconProvider`（Launch Services 查询，按 bundle ID 缓存，查不到的结果也缓存）。
- 语音输入显示 Typeflux 图标。
- 没有 bundle ID 的旧记录、已卸载的应用，回退到类型图标（媒体类型用符号，不再重复画缩略图），不需要数据迁移。
- 悬停显示应用名。副标题里的应用名保留，因为图标不一定认得出来，搜索也要用到它。

**媒体内联预览**（`ClipboardInlineMedia`，选中时原地放大，不再在下面另外展开）

| 类型 | 未选中 | 选中 |
|------|--------|------|
| 图片 | 64px 高，宽度按原图比例（48–220px），填满裁切 | 整行宽、168px 高，完整显示，右下角标出尺寸 |
| 多张图片 | 最多 3 张 56px 方图，其余显示为“+N” | 3 列网格（最多 6 张） |
| 视频 | 首帧缩略图，带播放标记和时长 | 内联 `AVPlayerView`，收起时停止播放 |
| 音频 | 波形条、播放图标和时长 | `ClipboardAudioPlayerView`：播放 / 暂停，点击波形跳转，已播放的部分变色 |
| PDF | 首页缩略图 50×64，右侧是文件名、页数和大小 | 首页 92×120，加上完整路径 |

- 文件名（媒体行）作为副标题的第一项，空间不够时先被截断；截图没有文件名，就只显示格式 · 尺寸 · 大小 · 来源 · 时间。
- 视频和音频在副标题里加上时长，PDF 加上页数（`ClipboardMediaInfoProvider`，异步读取并缓存）。
- 原文件丢失：显示占位图，不放大，保留“原文件已不存在”提示。

## 3. 性能
- 缩略图继续用 `ClipboardThumbnailProvider`。同一文件换尺寸时，先保留旧图，新图到了再替换，不会闪出占位图。
- 波形：每个文件只用 `AVAssetReader` 以 8 kHz 单声道解码一次（AVAssetReader 接受的最低采样率），最多扫描开头 10 分钟。结果按 180 个峰值缓存，各行再按自己的柱数取最大值重采样。行滚出可见区域时，解码随任务一起取消。
- 列表仍然是 `LazyVStack`，只渲染可见的行。

## 4. 已知局限
- macOS 不提供“谁写入了剪贴板”的接口，来源取的是复制时的前台应用。后台工具或脚本写入剪贴板时，会记到当时的前台应用名下。
- 超过 10 分钟的音频，波形只代表开头 10 分钟。
