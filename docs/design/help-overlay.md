**第 4 版（实现）**：按评审意见开发完成，并做了两处调整：

- **所有内容都跟随用户的设置**：快捷键、关键词、别名、自建关键词和工作流都从设置里实时读取。打开指南时会读取最新设置，打开期间改了快捷键、关键词或工作流，内容也会立刻更新。
- **对话和启动器是同一个功能**：应用里已经只有一个快捷键（`BuiltInHotkey.ask`，标题「启动器」）。指南不再把对话当成单独的入口，首屏合并为「启动器 · 对话」一张卡片，快捷键页也不再有单独的「对话 fn fn」。首屏因此变成上面两张卡片（语音输入、启动器 · 对话）、下面一张通栏的关键词卡片。

**第 3 版**：首屏从列表改成四张带小插图的入口卡片（§4.1）。插图会动：键帽按下、波形跳动、启动器里出现结果。「你还没试过」改成横排小卡片，启动器技巧改成一行标签。其他页面不变。

### 第 2 版

第 1 版的问题：直接在模糊的桌面上铺内容，没有容器；用了渐变 Logo、彩色标签（绿 / 紫 / 橙）和黄色标注，层级太多，和 Typeflux 中性灰的风格不一致；也没有区分 Liquid Glass 和经典两种界面风格。

第 2 版：

- **外观只用应用现有的 token**（`AskTheme`、`AskClassic`、`StudioTheme.accent`）：中性灰底色，强调色只用在选中项、主按钮和链接。关键词标签用启动器里的灰色标签样式（`launcherKeyword`），按键用 `keycapSurface` 键帽。去掉渐变、彩色标签和图标底色。橙色只用来标出需要处理的问题。
- **两种界面风格都支持**，跟随「设置 › 界面风格」，规则和笔记本、对话窗口一致（§3）。
- **结构更简单**：全屏遮罩 + 居中面板。面板布局是「侧栏 + 内容」，和笔记本、对话窗口相同。页面从 6 个减到 4 个，一次只显示一页，不再把所有内容排成一长页。
- **用分组列表代替卡片**：和设置窗口一样，用圆角分组里的 44pt 行。关键词页是「列表 + 详情」两栏。
- 设计说明写在设计稿上方的说明栏里，不再贴在画面上。

## 1. 需求理解

用户对应用感到困惑时，要能**快速**查到怎么用：

1. 不知道有哪些功能：需要能一眼看完的总览。
2. 忘了关键词或快捷键：需要搜索，而且要能搜到用户自己改过的名字。
3. 用了没效果：需要检查权限和服务状态，并看常见问题。
4. 看懂以后最好马上能试，不用先记下来再去操作。

现状：启动器里的 `prefix`（关键词目录）只列出关键词，不讲用法；对话命令 `/help` 什么都不做（`AskConversationModel+Commands.swift` 里是 `case .help: break`）；快捷键和关键词分别在两个设置页里。

## 2. 入口（`glass-dark-1-entry`）

| 入口 | 行为 |
|---|---|
| 启动器输入 `help` / `帮助` / `?` 后按 ↩ | 打开指南。使用现有的关键词机制：新增插件 `AskHelpPlugin`（`runsWithoutInput`、`entersOnReturn` 为 true），用户可以改名、加别名或停用 |
| `help 截图` | 打开指南，并把「截图」填进搜索框 |
| 启动器底栏的 ? 按钮 | 打开指南 |
| 对话命令 `/help` | 打开指南 |
| 菜单栏「使用指南…」 | 打开指南 |
| 全局快捷键 | 新增 `AppHotkeyAction.openHelp`，默认不设置 |

从启动器打开时，先关闭启动器。

## 3. 形态与两种界面风格

**全屏遮罩**覆盖鼠标所在的屏幕，包括菜单栏和 Dock。遮罩上居中放一个面板，大小为 1120 × 728pt；屏幕较小时按 90% 缩小，最小 900 × 600pt。点遮罩空白处或按 esc 关闭。

| | Liquid Glass | 经典 |
|---|---|---|
| 遮罩 | 桌面模糊 + 很淡的中性色调 | 不模糊，纯色压暗（深色 55%，浅色 28%） |
| 面板 | 玻璃（`AskGlassBackground`，`.floating`），圆角 26，顶部有高光描边 | 不透明，深色 `#1E1E1E`，浅色白色（`AskClassic.canvas`），圆角 12，细边框 |
| 侧栏 | 内缩 8pt 的玻璃面板，圆角 20（`askSidePanel`，`glassInset`） | 贴边，`AskClassic.sidebar` 底色，靠内容一侧有分隔线 |
| 选中项 | 半透明蓝色 + 细描边，图标变成强调色 | 系统源列表的中性灰（`AskClassic.selection`） |
| 行、搜索框、分段控件 | 行高 36、圆角 10，搜索框 34 / 12 | 行高 30、圆角 6，搜索框 28 / 7（`AskStyleMetrics.classic`） |
| 分组、按钮 | 分组圆角 14，按钮是胶囊形 | 分组圆角 10，按钮是圆角矩形 |

开启「减少透明度」或「增强对比度」时，Liquid Glass 也改用不透明面板（`AskGlassMaterial.resolve`）；macOS 13–15 用 `NSVisualEffectView` 代替。两种风格的布局和点击区域完全相同，只换材质和几何参数。外观跟随深色 / 浅色模式。

## 4. 面板结构

- **侧栏**：标题「使用指南」、搜索框（打开时就有焦点）、4 个页面，底部是官网链接、反馈方式菜单和版本号。「关键词」后面显示数量，「常见问题」有需要处理的项时显示橙色数字。
- **内容**：大标题 + 一行说明，右上角是关闭按钮。底部一行按键提示，写法和启动器底栏一样，用纯文字，例如「↑↓ 选择 · ↩ 在启动器中试一试 · esc 关闭」。
- 按键：直接打字就会搜索；⌘1–⌘4 切换页面；⌘F 聚焦搜索框；按 esc 先清空搜索，再按一次关闭。

### 4.1 开始（`*-2-start`）

首屏是用户打开指南后最先看到的地方，要做到一眼就看懂、愿意点进去，所以不用普通的列表。

- **四张入口卡片**（2 × 2）：语音输入、对话、启动器、关键词。每张卡片上半部分是小插图，下半部分是名称和一句说明。插图用 SwiftUI 绘制，只用应用里已有的元素：
  - 语音输入：`fn` 键帽按下 → 强调色的波形 → 文字逐字出现，后面跟着光标。
  - 对话：`fn` 键帽连按两次，右上角有「×2」角标，旁边是一条问答气泡。
  - 启动器：`⌘` + `Space` 两个大键帽。
  - 关键词：一个迷你启动器，输入「`fy` hello world」后出现选中的结果行「你好，世界」。
  - 键帽显示用户**当前**的绑定。动画只在显示时循环播放；开启「减少动态效果」时显示静止画面。
  - 语音输入卡片仅展示说明。启动器卡片悬停时描边变成强调色，右下角显示「试一试 →」，点击打开启动器并保留指南；点「关键词」卡片跳到关键词页。
- **你还没试过**：横排 3 张小卡片，每张是关键词标签、名称和说明。根据 `AskKeywordUsage` 选 3 个没用过的内置关键词，按固定顺序取，不随机；全部用过时不显示这一组。点击进入关键词页并选中它。
- **启动器里不用关键词也能做**：一行胶囊标签（经典风格是圆角矩形）：`12*(3+4)` 直接算、输入应用名打开、空输入框按 ↑ 找回最近输入、先选中文字再打开启动器。

两种界面风格的区别：Liquid Glass 的卡片是半透明的，插图区比卡片再透明一层；经典风格的卡片不透明，插图区用 `AskClassic.sidebar` 的灰色，键帽和卡片的圆角也更小。

### 4.2 关键词（`*-3-keywords`）

- 数据和启动器、`prefix` 是同一份：`settings.askLauncherKeywords` + 工作流 + 系统命令。用户改过的名字、别名、自建关键词和工作流都会显示；停用的变灰，并写明原因。
- 分段控件：全部 / 文字 / 搜索 / 截图 / 工具 / 我的 / 系统。分组来自插件的 `helpCategory`；自建关键词和工作流放在「我的」。
- 每行：图标、名称、一句说明；右侧是已绑定的快捷键，以及关键词和别名。
- **右侧详情**（340pt）：说明、能否处理选中文字、示例、结果上的按键、全局快捷键（未设置时可以点「设置…」）、使用次数。示例可以点：保留指南，打开启动器并填好内容，由用户按 ↩ 运行。底部是「编辑」和「在启动器中试一试 ↩」。
- 用 ↑↓ 切换选中项，详情跟着变；按 ↩ 试一试。

### 4.3 快捷键（`glass-dark-4-shortcuts`）

- 全局：所有 `BuiltInHotkey` 和 `AppHotkeyAction`。未设置的显示蓝色的「未设置」，点了打开快捷键设置。
- 关键词快捷键：执行方式写在副标题里。
- 启动器、结果、对话窗口：固定按键，来自一份集中维护的表（§6），避免和代码不一致。
- 命令：由 `AskCommand.all` 生成的 `/` 命令，分两列显示。

### 4.4 常见问题（`*-7-faq`）

- **状态**：麦克风、辅助功能（`PrivacyGuard`）、语音识别、文本处理模型。正常的显示绿色圆点和灰色说明；有问题的显示橙色圆点、橙色说明和「去授权」按钮。授权后状态立即刷新。
- **问题**：可展开的列表。和当前状态有关的问题标出「可能和你有关」，并自动展开第一个。答案里的「设置 › …」可以点，点了打开对应的设置页。

## 5. 搜索（`glass-dark-5-search`、`glass-dark-6-empty`）

- 一起搜：关键词和别名、名称、说明、快捷键、命令、常见问题。
- 按键的写法会先转换再匹配：cmd → ⌘，opt / alt → ⌥，ctrl → ⌃，shift → ⇧，enter / return → ↩，并忽略空格。中文名称支持拼音，复用 `AskAppEntry` 里已有的拼音匹配。
- 结果按类型分组，命中的文字用强调色的淡底标出。按 ↑↓ 选择，按 ↩ 打开：关键词打开详情，其他跳到所在页面。
- 没有结果时显示「问 AI ⌘↩」：关闭指南，在启动器中把问题交给 AI，并附上一份由 §6 数据生成的帮助摘要（包含用户当前的关键词和快捷键）。

## 6. 实现要点（确认设计后）

| 模块 | 内容 |
|---|---|
| `Ask/QuickResults/Plugins/AskHelpPlugin.swift` | 关键词 `help`，别名 `帮助` 和 `?`；`plan` 返回 `.openHelp(query:)` |
| `Help/HelpCatalog.swift` | 纯数据：把关键词、插件元数据、快捷键绑定、命令、固定按键表和常见问题组装成页面和条目，不依赖 UI |
| `Help/HelpSearch.swift` | 纯函数：规范化按键写法、拼音、打分、分组 |
| `Help/HelpOverlayController.swift` | 全屏 `NSPanel`：选择鼠标所在的屏幕，处理焦点和 esc |
| `Help/HelpOverlayView*.swift` | SwiftUI：复用 `askSidePanel`、`AskGlassBackground`、`AskStyleMetrics`、`AskClassic`，通过 `interfaceStyle(following:)` 跟随界面风格 |
| `AskLauncherPlugin` | 新增可选的 `helpCategory`、`helpExamples`、`helpKeys`，提供默认实现 |
| `AppHotkeyAction.openHelp`、`/help`、菜单栏 | 都调用 `HelpOverlayController.show(query:)` |
| 本地化 | 所有文案进 `Localizable.strings` |

测试：

- `HelpCatalogTests`：改名、停用、自建和工作流关键词；未设置的快捷键；每个内置插件都有分类。
- `HelpSearchTests`：按键写法转换、别名、拼音、没有结果。
- `AskHelpPluginTests`：`help xxx` 把查询传给指南。
- `AskCommandsTests`：`/help` 打开指南。
- 两种界面风格 × 深浅色的渲染冒烟测试和截图。

目标覆盖率 ≥ 90%。

## 7. 实现说明

| 设计 | 实现 |
|---|---|
| `help` / `帮助` 关键词 | `AskHelpPlugin`。`help 截图` 打开指南并搜索「截图」。**没有加 `?` 别名**：单独一个符号容易和提问冲突，这一点之前也没有确认 |

| 启动器底栏的 ? 按钮 | **没有做**。上面四个入口已经覆盖，避免改动启动器底栏 |
| 在线文档链接 | 指向官网 `https://typeflux.app`（没有确认过的文档地址）；反馈链接与菜单栏相同 |
