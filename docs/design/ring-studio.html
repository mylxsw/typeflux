一句话：圆环本身就是编辑器。在圆环上点「+」就在那个位置插入，右侧面板直接浏览、搜索、一键添加，悬停即在圆环里预览；改名、换图标、调位置都实时生效，删除可撤销。没有弹窗，没有「保存」。

2. 设计原则

  1. 直接操作：在哪里点「+」就加在哪里；拖动圆环上的图标就是调整位置。
  2. 先看见，再决定：所有可选操作平铺可浏览；悬停一项，圆环的空位里立即出现它的图标和名字。
  3. 一次点击完成添加：点选即加入，随后右侧自动进入该项的编辑态，可以顺手改名/换图标（可选，不改也行）。
  4. 无模态、即时生效：与 macOS 系统设置一致，没有「保存/取消」。
  5. 宽容：删除、替换、恢复默认都给「撤销」（⌘Z），不再弹确认。
  6. 键盘等价：每个鼠标操作都有键盘路径，方便高频用户与无障碍。

3. 布局

「操作」卡片变成左右两栏的 Ring Studio：左 440pt 为圆环画布（深色壁纸底，所见即运行时外观），右侧为检查器，有三种状态：

状态进入方式内容
总览默认；Esc；点击画布空白按顺时针列出操作（序号＝数字键，附方向），可拖动排序；末尾「添加操作」（追加到最后）
操作库点圆环上的 ⊕ / 「添加操作」/ 编辑态的「更换」顶部说明插入位置；全局搜索；推荐；8 个类型卡片 → 进入类型列表（带分组和搜索）；快捷键/网址/文件夹类是内联表单
编辑点圆环上的图标或列表行；添加完成后自动进入名称（可直接改）、图标、动作（可「更换」，参数内联编辑）、位置（顺/逆时针移动）、复制、删除

4. 关键流程

4.1 在指定位置添加

  1. 圆环外沿每两个操作之间有一个 ⊕（悬停画布时变亮，悬停 ⊕ 放大变蓝）。
  2. 点 ⊕ → 圆环立刻在该处让出一个虚线空位（编号随之变化），右侧切到操作库，搜索框获得焦点。
  3. 悬停/方向键移动到某项 → 空位实时显示该项图标与名称。
  4. 点击或 ↩ → 加入，空位变实，右侧进入该项编辑态，toast「已添加到右下方 · 撤销」。
  5. Esc / 返回 / 点画布空白 → 取消，空位收回。

4.2 操作库

  • 搜索覆盖全部类型（功能、关键词、系统、快捷指令、应用、文件夹），结果按类型分组，命中高亮；输入像网址的文本时首项是「打开网址 …」，像路径时是「打开文件夹 …」。
  • 未搜索时：「推荐」一行（尚未加入的高频项），下面是 8 个类型卡片，每张写清作用与数量。
  • 已在圆环里的项显示「已添加」标签，仍可再加（例如不同名字）。
  • 快捷键：大号录制区 + 常用组合预设；网址：输入框 + 实时校验；文件夹：常用文件夹 + 「选择文件夹…」。

4.3 编辑与排序

  • 名称、图标、参数实时写入并反映到圆环；名称清空即恢复默认名称。
  • 位置：在圆环上直接拖图标到别的扇区；或编辑态「逆时针 / 顺时针」按钮；或 ⌥←/⌥→。
  • 「更换」进入操作库替换模式：保留位置；若名称/图标未自定义则随新动作更新。

5. 键盘

按键（画布聚焦）作用
← / →（或 ↑ / ↓）逆/顺时针选择上一个/下一个操作
⌥← / ⌥→把选中的操作逆/顺时针移动一格
1–8选中对应序号的操作
+ 在选中项之后插入（未选中则追加）
↩编辑选中项（聚焦名称）
Delete删除选中项（可撤销）
Esc取消添加 / 退出编辑
⌘Z撤销上一次删除、替换、添加、排序或恢复默认
操作库中 ↑ / ↓ / ↩在结果中移动（圆环同步预览）并添加

7. 实现映射（SwiftUI）

  • 数据结构 RingConfiguration / RingAction 不变，无需迁移。
  • RingSettingsModel 新增 insert(_:at:)、replaceKind(of:with:)、move(_:by:)（已有）和一个有界撤销栈（最近 20 步）。
  • RingPreviewView → RingStudioCanvas：增加插入槽位、占位扇区、选中描边、拖动排序、序号；hit-test 复用 angleIndex。
  • 新增 RingInspector（enum RingInspectorState { overview, library(RingLibraryTarget), edit(UUID) }）。
  • 新增 RingActionLibrary：把 RingFeature、RingSystemAction、关键词、PersonaAppDiscovery 应用、快捷指令（/usr/bin/shortcuts list）、常用文件夹聚合成可搜索条目。
  • 删除 RingActionEditorSheet 和两处删除确认 alert。
