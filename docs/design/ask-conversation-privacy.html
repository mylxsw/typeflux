随便问 · 用「私密对话」替代「本机模式」

现在的“本机”是一个全局开关：打开后，云端历史整个被藏起来，云端模型不能选，组件上只显示“本机”两个字。用户分不清它说的是模型在本机跑，还是数据存在本机。新方案把它降级为每个对话自己的属性：普通对话同步到 Typeflux Cloud，私密对话只存在这台 Mac 上。两种对话出现在同一个列表里，靠锁形图标和紫色区分。“模型在哪里运行”只放在模型选择器里说明。
下面的窗口可以直接操作：点输入框左下角的存储图标（☁ 云端同步 / 🔒 仅存本机）、顶部的新建按钮、模型名称和侧边栏筛选；发送消息试试。窗口上方的工具条可以切换登录状态和明暗主题。

账号
主题

现状（截图中的状态）

  • 输入框胶囊 本机：看不出它表示的是存储位置、模型还是执行位置。
  • 卡片写“在这台 Mac 上运行”，但模型来源是“自定义”远程 API，其实仍然联网。
  • 打开开关后，侧边栏只显示本机历史，云端对话“消失”。
  • 切换开关后会话不会立即重置，所以“本机”胶囊会和云端对话的 160.79 credits 同时出现。
  • 已登录用户在卡片里没有办法切回云端。

方案要点

  • 存储：每个对话单独决定。输入框里只放一个图标（☁ 或紫色 🔒），悬停显示名称，点击弹出详情卡片；只在空对话里可以改；发出第一条消息后就固定，点击只解释原因，不会出现半同步的对话。
  • 历史：合并成一个列表，私密对话带锁形图标，可以按「全部 / 云端 / 仅本机」筛选。
  • 模型：选择器把“在哪里运行”标成标签，例如「Ollama · 在本机运行」「API · 联网调用」。私密对话里，云端模型置灰并写明原因。
  • 新对话页和内容区：两种模式完全一致，保持现状（标题、提示、占位符都不变）。差异只体现在输入框图标、标题栏右侧、侧边栏锁形图标和模型选择器。
  • 计费：credits 只在云端对话的标题栏显示。私密对话改为显示「仅存本机」。
  • 未登录：所有对话自然都是私密对话。底部卡片显示“未登录 · 对话仅存本机”，新建菜单里“云端对话”显示为登录后可用。
  • 设置：「使用本机对话模式」开关改为「新对话默认：云端同步 / 仅存本机」。

试试这些操作

三个维度拆开

  • 对话存在哪：对话属性，用锁形图标和紫色表示。
  • 用哪个模型：模型选择器，标签注明模型是在本机运行还是联网调用。
  • Agent 在哪执行：实现细节，不对用户展示。私密对话走 AskLocalEngine，云端对话走服务端。

实现映射

  • AskRoutedAPI：路由依据从“token 是否为空”改为“对话的 storage”。
  • 列表合并：同时读取 owner=local 和账号 owner 的缓存，按时间合并，再带上来源标记。
  • askLocalModeEnabled → askNewConversationPrivate，旧值直接迁移。
  • 文案替换：ask.location.local* / ask.local.card.*。
