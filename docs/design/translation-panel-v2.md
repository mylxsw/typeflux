## 0. 一页结论

| | 改版前 | v2 |

## 2. 设计原则

1. **一块玻璃**：面板本身是唯一的 Liquid Glass 表面。内部控件不加材质、不加描边，悬停时才出现底色（符合「控件不叠玻璃」）。
2. **内容优先**：译文用 14.5pt，是面板里最醒目的内容；服务名、标签、序号都用 12pt 以下的二、三级文字色。
3. **操作按需出现**：常驻的只有语言对、历史、钉住、⋯。每一项的操作在悬停或选中时出现，键盘用户靠 ⌘1–9 和 ⌥↩。
4. **反馈不打断**：复制、插入、朗读的结果在底栏显示 1.6 秒，被操作的那一项闪一下，复制图标变成 ✓。
5. **和其它页面一致**：圆角、字号、颜色都用 `AskMetrics` / `StudioTheme` 里已有的值（§5），Classic 和「减少透明度」走现有的回退规则。

## 3. 布局与交互

### 3.1 结构（自上而下）

```
╭────────────────────────────────────────────────────────────╮
│ 检测到 英语 ⌄   ⇄   简体中文 ⌄            [⌶ 划词] 🕘 📌 ⋯ │  标题栏 46pt，空白处可拖动
│                                                            │
│ good                                                       │  原文 17/25pt，最多 4 行后滚动
│ 4 字符                         [↩ 翻译]        🔊 ⧉ ⓧ    │  元信息 26pt；图标悬停显示
│ ────────────────────────────────────────────────────────── │  发丝线（左右各缩进 14pt）
│ ⌄ ✦ AI · typeflux/assistant [单词本]   ☆ ↻ 🔊 ↵ ⧉   ⌘1 │  结果标题行 24pt
│     good  好的；优良的                                      │
│     (UK /ɡʊd/ 🔊) (US /ɡʊd/ 🔊)                            │
│       adj. 好的，优良的；令人满意的…                        │
│         n. 好处，利益；善行，好事                           │
│       adv. 好地，很好地（非正式用法）                       │
│     变形 比较级 better  最高级 best  名词 goodness …       │
│     例句 This is a good book for beginners.               │
│          这是一本适合初学者的好书。                         │
│          更多例句                                          │
│     近义 (fine) (nice) (excellent) …   ← 点击查词          │
│   对照                                                     │
│   ▣ 本机翻译  好                                     ⌘2   │
│   有 有道     好的；良好的；善良的                    ⌘3   │
│ ────────────────────────────────────────────────────────── │
│ ↩ 复制   ⌘S 收藏   ⌘B 单词本                           ⌨  │  底栏 32pt
╰────────────────────────────────────────────────────────────╯
```

- 默认宽度从 700pt 改为 **640pt**（一行约 40 个汉字，更适合阅读）；最小尺寸、可调整大小、最大高度的规则不变。
- 打开位置、钉住、失焦关闭的规则不变。划词翻译时面板出现在选区旁边（设计稿「网页」背景下的「单词释义」画面）。

### 3.2 标题栏

- **源语言**：`检测到 英语 ⌄`；手动指定后显示语言名。**目标语言**用 accent 色，表示它是可以切换的「输出」。
- **⇄**：交换语言，并把第一项译文放回原文（⌘⇧S），按钮旋转 180°。
- 语言弹层：顶部是搜索框（自动获得焦点，↩ 选第一项），然后是「最近使用 · ⇥ 轮换」，最后是全部语言，当前语言前面有 ✓。
- **入口标签**（划词 / 输入 / 截图）：小号胶囊，只做说明，不可点击。
- **🕘 历史**：最近的翻译和时间，底部是「清空历史」。
- **📌 钉住**：钉住后变成实心 accent，底栏左侧显示「已钉住」。
- **⋯**：打开单词本 ⌘B、复制原文 + 译文、快捷键、管理翻译服务…、翻译设置… ⌘,。

### 3.3 结果

- 每一项：`⌄` 收起，服务图标（18pt，圆角 5pt），名称，AI 的模型名，标签（不出本机 / 单词卡 / 单词本），然后是靠右的操作和 `⌘n`。
- **选中**：`accentSoft` 填充；**悬停**：`hoverFill`；两者都会隐藏相邻的分隔线，避免出现一条线穿过色块。
- **加载**：骨架屏（两行 shimmer），本机和服务商整段出现，AI 流式输出并带光标。
- **失败**：一行 ⚠ 原因 + 一个下一步按钮（去配置 / 重试 / 本次跳过），文案沿用 GUL-369 §3.3。
- **单词卡**：
  - 词头 26pt semibold；简明释义 15pt accent，和词头放在同一行。
  - 音标是两个胶囊按钮，点击朗读，播放时图标变成 accent。
  - 释义、变形、例句、近义词共用一列 38pt 的标签列（词性用斜体、右对齐）。
  - 例句：原文里的词头用 accent 加粗，译文里 `**…**` 的部分用一级文字色加粗；悬停时出现朗读按钮。
  - 近义词是胶囊按钮，点击后以这个词为原文重新查（新增）。
- **对照**（查词时）：其它服务各占一行，图标 + 名称 + 简短译文，悬停时出现插入和复制。

### 3.4 原文

- 没有边框和底色；输入光标用 accent 色。
- 有改动但还没翻译时：元信息行出现「↩ 翻译」，下方的结果降到 55% 不透明度（不清空，高度不跳）。
- 原文语言已经和目标语言相同时，下方出现一行：「原文已经是简体中文。**译成英语**」。
- 截图翻译：原文上方显示缩略图和「识别自截图 · n 行 · 可以直接改错字再按 ↩」。
- 空白时，元信息行显示「↩ 翻译 · ⇧↩ 换行 · ↑ 翻历史」，结果区显示最近查过的单词和翻译历史。

### 3.5 键盘

沿用 GUL-369 §5，不新增、不改动语义。新增 `?`（焦点不在原文时）打开快捷键面板。esc 的顺序：快捷键面板 → 弹层 → （钉住时）清空原文 → 关闭面板。

## 6. 已确认的决定

1. 面板默认宽度改为 640pt（`AskTranslationPanelPlacement.width`）。启动器 `fy` 仍为 700pt。
2. 「单词本」入口移到 ⋯ 菜单，⌘B 不变。
3. 点击近义词会直接查这个词（`AskPluginAction.Kind.runWith`），按 ↑ 翻历史可以回到上一个词。

## 7. 实现说明

| 设计稿 | 实现 |
|---|---|
| 标题栏里的语言对 | `AskTranslationLanguagePair`，面板和启动器 `fy` 共用；面板里给 `AskTranslationStackView` 传 `showsLanguageBar: false` |
| 无框结果行、发丝线、对照标签 | `AskTranslationResultView`：选中用 accent 14% 填充，悬停用 `hoverFill`；分隔线在选中行旁边隐藏 |
| 单词卡排版 | `AskWordCardView` 的 stack 样式：`stackContents`、`stackContentHeight`、`emphasizedTarget`。启动器里的独立单词卡不变 |
| 标题行操作 | 单词卡的收藏和重新生成改成图标，和朗读、插入、复制放在一起；不再显示底部的四个按钮 |
| 底栏 | 显示 3 个上下文提示；复制或插入后，`AskTranslationPanelModel.flash` 在底栏显示 1.6 秒确认；⌨ 打开 `AskTranslationShortcutSheet` |
| 空白状态 | 列出最近 5 条翻译历史，点击后直接翻译 |

设计稿里有两点没有照搬：
- 改了原文以后，旧结果会被清空，不会变淡后保留。这沿用现有的 `text` didSet 行为，避免把旧译文误当成新原文的结果。
- 快捷键说明是 ⌨ 按钮打开的原生 popover，没有做成全屏遮罩。
