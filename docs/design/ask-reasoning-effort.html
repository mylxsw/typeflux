随便问 · 模型与推理强度选择器（v2）

按反馈调整了三处：① 卡片左上角的闪电去掉了；② 强度最多五档（轻度 · 中等 · 高 · 超高 · 极致），滑杆上只显示当前模型实际支持的档位，换到档位较少的模型时，自动落到最接近的一档；↺ 恢复为「自动」，由模型自己决定；③ 进度条重做：凹进去的轨道、带光泽的凸起滑块，填充区里有像水一样缓慢流动、闪烁的光点，最高档变成紫色，并且最高档时进度条完全填满。
下面的方案可以直接操作：拖动或点击滑杆，按 ←/→ 键调整，点模型名切换模型（Claude Sonnet 5.5 支持五档，MiniMax M3 支持三档，GPT-5.5 mini 不支持调节）。

视觉

  • 轨道是凹进去的，带内阴影；滑块是凸起的白色，带光泽和阴影。
  • 填充是蓝色渐变，上半部分有一层高光；里面的光点持续向右缓慢流动、闪烁，还有一道柔和的光带周期性地扫过，模拟水流。
  • 极致档换成蓝紫到紫色的渐变，档位名、输入框按钮上的档位文字也一起变紫。
  • 填充一直延伸到滑块右边缘，所以最高档时完全填满；未填充部分保留档位圆点。
  • 标题区去掉了闪电图标，只保留「档位名 / 模型名 ›」和 ↺。

实现说明

  • AskReasoningEffort 扩成五档加自动；每个模型支持哪些档位来自模型目录（新增 reasoningEfforts 字段）。自定义模型默认低 / 中 / 高三档，服务商拒绝时沿用现有的回退逻辑。
  • 更高的两档（超高、极致）需要服务端和模型网关支持对应参数，否则不会出现在滑杆上。
  • 填充动画在 SwiftUI 里用 TimelineView + Canvas 绘制；开启「减少动态效果」时停止流动，只保留静态光点。
