笔记本改版 — 交互设计稿

GUL-322。笔记本定位为 Markdown 笔记本：收集聊天和 AI 指令中保存的内容，也能自己新建、编辑、整理、导出。外观沿用单词本改版的 Liquid Glass 窗口。说明文档：docs/design/notebook-redesign.md。所有按钮都可以点；按键：⌘N 新建、⌘E 阅读 / 编辑、⌥⌘E 分栏、⌘F 过滤、↑↓ 切换、esc 退出编辑。

场景

入口：在对话里存入笔记本 · nb 关键字新建

Agent 使用笔记本：内置技能 notebook + 本机工具 notebook

  • 技能负责「什么时候、怎么用」：用户提到「我的笔记 / 之前存的 / 笔记本里那条」或要「存到笔记本」时，模型先加载 notebook 技能，按里面的规则搜索、引用、写入。
  • 工具负责「能做什么」：notebook 一个工具多个 action（search / read / list / create / append / update / tag / delete），和 memory、files 同一套设备工具机制，云端对话和私密对话都能用。
  • 笔记只在本机：读到的内容会发给当前对话的模型，所以读取走「读取」级确认，可在设置里改成「读取不再询问」；写入走「修改」级确认并预览改动；删除只进「最近删除」。
  • 回答里引用笔记：引用以笔记卡片显示，点开跳到笔记本对应位置。
  • MCP：同一组操作以本机 MCP 服务 typeflux-notebook 暴露给其他客户端（Claude Desktop、Cursor 等），默认关闭，放在 P5。
