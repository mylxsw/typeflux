翻译：查词记录与单词收藏

GUL-237 设计稿。查过的单词与短语自动记进「单词本」，在启动器里按 ⌘S 收藏；输入 fy 不带内容时列出最近查过的词；工作台新增「单词本」页面，用来复习、搜索、整理和导出。下面四块都可以操作，并且共用同一份数据：在 ① 里收藏的词，③ 里立刻能看到。

键盘：先点一下 ① 或 ② 的桌面区域让它获得焦点。⌘S / Ctrl+S 收藏，↑↓ 选择，↩ 打开。

  • 什么会被记录：只记单词和短语（沿用 AskWordCard.isLookup 的判断）。句子是翻译，不进单词本，卡片上也没有 ☆。
  • 什么时候记：结果「落定」时才记一次——AI 单词卡在结果出来时；本机边输边译的结果要等用户对它做了操作（复制、插入、朗读、收藏、⌘R），或者它停留 1.5 秒后关闭启动器。这样输入 s → se → ser… 的中间状态不会被记下来。
  • 再次查同一个词：不新增行，「查过 N 次」+1，最近时间更新。同一次打开启动器里反复出现只算一次。
  • 省钱：单词本里已有 AI 单词卡的词，再查直接显示存下来的卡（右下角写「来自单词本」），不再请求模型；⌘R 才重新生成并覆盖。
  • 本机译文也能收藏：保存的是简短译文；之后按 ⌘R 生成单词卡，会升级同一条记录，收藏状态不变。
  • 收藏 / 取消的反馈出现在底栏左侧（短暂替换来源文字），不遮挡卡片；⌘S 再按一次即撤销。

  • 两个视图：「收藏」默认，用于复习；「查词记录」是全部记录（含收藏），按天分组。搜索同时匹配单词和释义；可按语言方向筛选；四种排序。
  • 详情：直接复用启动器的单词卡视图（AskWordCardView），点击释义复制、可朗读。本机译文的记录显示译文，并提供「用 AI 生成单词卡」。
  • 整理：☆ 收藏 / 取消；删除记录带撤销；「重新生成」调用 AI 覆盖卡片（明确标出会发送到哪个模型）。
  • 导出：CSV / Markdown / Anki TSV，导出当前视图（受搜索、筛选影响）。
  • 记录设置：可关闭记录；保留期只清未收藏的；一键清空查词记录，收藏保留。
  • 空状态：没有收藏时提示「在启动器的单词卡上按 ⌘S 收藏」；关闭记录时，「查词记录」顶部提示已暂停。
  • 数据只在本机（word-book.sqlite）。云同步收藏放到后续阶段，见方案文档 §6。
