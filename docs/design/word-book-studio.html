单词本 UI 重构 · 与主窗口统一（GUL-251）

单词本不再用 Liquid Glass 和彩色光晕，改用主窗口（概览 / 词库 / 历史 / 模型）的样式：平铺的深色画布、平铺侧栏、带细边框的卡片、中性灰的选中态，强调色只用于焦点、主按钮和链接。下面的窗口可以直接操作：切换分类、过滤、排序、选词、收藏（⌘S）、复制释义、删除后撤销、顶部查词（输入 gregarious 回车看生成过程）、导出与设置弹层。

部位现在（GUL-237 Liquid Glass）改为（与主窗口一致）
窗口背景毛玻璃底 + 左上蓝色、左下紫色两团径向渐变平铺 StudioTheme.windowBackground，无渐变、无光晕
侧栏悬浮圆角玻璃面板，与窗口边缘留缝贴边平铺侧栏（210pt，与主窗口同宽），右侧 1px 分隔线；顶部图标 + 「单词本」
侧栏选中蓝色半透明底 + 蓝色图标中性灰 sidebarSelection + 加粗文字，与主窗口导航一致；收藏仍保留黄色星
标题列表顶部 15pt 小标题页面级 23pt 标题 + 词数，位置和主窗口各页面相同（顶部 52pt 区域）
查词栏居中的发光胶囊，聚焦时蓝色光圈标题右侧的普通输入框（8pt 圆角、细边框），和模型页搜索框同一形态；方向切换是框内的小按钮
列表直接铺在玻璃背景上，选中是蓝底 + 蓝描边放进 StudioCard（12pt 圆角、细边框）；行间内缩分隔线；选中为中性灰；排序改为原生样式的弹出按钮
详情34pt 词头 + 半透明卡片 + 底部悬浮玻璃操作条整块放进一张卡片：头部（元信息、30pt 词头、音标按钮、收藏按钮），下面一条固定工具栏（复制释义 / 朗读 / 问 AI / 重新生成 / 删除），内容按「释义 · 例句 · 近义词与词形 · 查词记录」分组
徽标颜色紫色「AI 卡」、黄色收藏底、绿色「本机」描边，多色并存徽标统一为中性灰胶囊；只有「新词」用强调色，收藏只给星形图标着色
底部统计侧栏底部裸放数字和蓝色柱条放进与主窗口账户卡同款的小卡片；柱条为中性灰，仅「今天」用强调色
空状态蓝底大图标中性图标块 + 一张三行上手提示卡片 + 「查第一个词」主按钮
提示条 / 弹层玻璃胶囊与主窗口弹层相同的实底卡片（细边框 + 轻阴影）
  • 交互与快捷键不变：⌘L 查词、⌘F 过滤、↑↓ 选词、⌘S 收藏、⌘C 复制释义、⌫ 删除、⌘Z 撤销、esc 逐级退出；功能、数据和文案均沿用现有实现，本次只改外观与布局。
  • 窄窗口：宽度小于 980pt 时侧栏收成 60pt 图标列，导出和设置移到图标列底部；列表卡片缩为 260pt。
  • 浅色外观：与主窗口浅色同一套 token（白色卡片、浅灰侧栏），切换右上「外观」查看。
