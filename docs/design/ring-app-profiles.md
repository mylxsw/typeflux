# 圆环：应用级设置

> 状态：设计稿，待评审（GUL-471）。可交互设计稿：`docs/design/ring-app-profiles.html`。
> 顶栏切换：① 设置页、② 运行时圆环（在模拟桌面上按住 Space 打开圆环，点中心切换）、③ 设计说明；场景可选「已有 3 个应用 / 尚未设置应用 / 刚添加应用 / 应用已卸载」，以及浅色 / 深色。
> 基础交互见 `ring.md`，设置页编辑方式（Ring Studio）见 `ring-studio.md`。本方案在两者之上增加「按前台应用切换操作」，不改变已有的编辑方式和手势。

## 0. 一页结论

- 圆环仍然只有**一个触发键、一套外观**。操作分为两层：**全局操作**，以及**为某个应用单独设置的操作**。
- 打开圆环时，如果当前前台应用有专属设置（已启用且至少 1 个操作），先显示**应用圆环**。中心显示该应用的图标和名称，下方的两个圆点表示有两页。
- **单击中心的圆，在应用操作和全局操作之间切换**；再点一次切回。键盘用 `Tab` 切换。没有专属设置的应用，中心保持现在的样子（文字 + 操作数），单击仍是关闭圆环。
- 设置页的「操作」卡片顶部增加一排**范围标签**：`全局` | `Safari` `Xcode` … | `＋ 添加应用`。选中哪个，下面的 Ring Studio 就编辑哪一组。编辑方式和现在完全一致（⊕ 插入、操作库、即时生效、撤销）。
- 应用圆环的操作库会把**这个应用的常用快捷键**放在最前面（如 Safari 的「新建标签页 ⌘T」、Xcode 的「构建 ⌘B」）。这是应用级圆环最常见的用法。

## 1. 运行时：打开与切换

### 1.1 选哪一组

打开圆环那一刻读取前台应用（就是 `RingController.previousApplication`，也是「发送快捷键」的目标应用），按 bundle identifier 匹配：

| 前台应用 | 先显示 | 中心 | 单击中心 |
|---|---|---|---|
| 有设置、已启用、≥1 个操作 | 应用圆环 | 应用图标 + 名称 + 页码点 ●○ | 切到全局圆环 |
| 同上，已切到全局 | 全局圆环 | 中心文字 + 「N 个操作」+ 页码点 ○● | 切回应用圆环 |
| 没有设置 / 已停用 / 0 个操作 | 全局圆环 | 中心文字 + 「N 个操作」（现状） | 关闭圆环（现状） |
| Typeflux 自己在前台 | 全局圆环 | 现状 | 现状 |

- 每次打开都**从应用圆环开始**，不记住上次切到哪一页。理由：应用圆环是用户为这个场景专门准备的；记住全局页会让下一次打开变得不可预测。
- 全局圆环为空、应用圆环不为空时，中心不提供切换（没有可切换的目标），只显示应用圆环。
- 两组都为空时，触发键不注册（沿用 `isUsable` 规则，改为「全局或任一已启用应用有操作」）。

### 1.2 切换手势

| 输入 | 行为 |
|---|---|
| 鼠标单击中心圆（半径 48pt 内） | 切换。圆环保持打开，指针位置不变 |
| `Tab` | 切换（键盘打开或轻按打开时） |
| 悬停中心 | 中心描一圈蓝色高亮，下方气泡「切换到全局操作 Tab」/「切换到 Safari 操作 Tab」 |
| 按住触发键 → 移回中心 → 松开 | **取消**（现状不变）。松开触发键和单击鼠标是两件事，不会误切换 |
| 按住触发键时单击中心 | 也切换。之后松开触发键，按指针方向执行或取消，和现在一致 |

切换动画（约 0.28s）：扇区组从 -24° 转入、0.88 倍放大到 1、淡入；中心内容做一次水平翻转。扇区数量不同（如 6 ↔ 7）时重新均分。悬停音效在切换后的第一次悬停照常播放。

数字键 `1–8`、方向键、`↩` 始终作用于**当前显示**的那一组。

### 1.3 执行

- 两组操作的 id 都是 UUID，`select(id)` 在当前显示的那组里查找；「复制全局操作」生成新 id，不会与全局重复。
- 「发送快捷键」发给打开圆环时的前台应用（现状），在应用圆环里这正是该应用。

## 2. 设置页

### 2.1 布局

「操作」卡片自上而下：

1. **范围标签栏**（高 52pt，横向滚动）：
   - `🌐 全局 6` — 始终第一个。
   - 分隔线后是各个应用：应用图标 + 名称 + 操作数。已停用的图标和名字变淡，数字处显示「已停用」。找不到的应用在图标右上角带黄点。
   - 末尾 `＋ 添加应用`（没有任何应用设置时文案为「为应用单独设置」）。
2. **范围信息栏**（高 50pt）：
   - 全局：地球图标、「全局圆环」、副标题「其他所有应用」（无应用设置时为「所有应用」）、右侧「恢复默认」（从原来的分区标题处移到这里，只属于全局）。
   - 应用：应用图标、名称、bundle id（等宽小字）、「启用」开关、`⋯` 菜单：「用全局操作替换」「在 Safari 中试一试」「删除 Safari 的设置」。
3. **Ring Studio**（440pt 画布 + 检查器，高 520pt）：与 GUL-470 完全一致，只是编辑对象换成当前范围。

外观（样式、中心文字、悬停音效）和触发键保持全局，不按应用区分。「中心文字」的说明改为「全局圆环的中心文字。应用圆环的中心显示应用图标和名称。」

### 2.2 画布上的变化

- 应用范围下，画布圆环的中心和运行时一样：应用图标 + 名称 + 页码点。
- **单击画布中心 = 预览全局圆环**（与运行时同一个动作、同一个动画）。预览时左上角显示「全局圆环 · 预览」，右上角「编辑全局」；⊕ 隐藏；点预览中的某个扇区，直接跳到全局范围并选中它。再点中心返回。`Tab`（焦点在画布上时）同样切换。
- 「试一试」在应用范围下变为「在 Safari 中试一试」。
- 停用的应用：圆环降到 45% 不透明度，左上角加「已停用」胶囊，仍可编辑。

### 2.3 添加应用

点「＋ 添加应用」弹出选择器（320pt 宽）：

- 顶部搜索（名称或 bundle id），`↑ / ↓ / ↩ / Esc` 可用。
- 「正在运行」分组在前（绿点），其次「其他应用」。数据源与操作库中的应用相同（`PersonaAppDiscovery`）。
- 已设置的应用显示「✓ 已设置」并不可选。
- 底部「选择其他应用…」打开 `NSOpenPanel`（`/Applications`，只允许 `.app`）。

选定后：

1. 新增一个空的应用设置（已启用），切换到它。
2. 画布显示虚线空圆环 + 蓝色大 ⊕「添加第一个操作」，下方次要按钮「复制全局的 6 个操作」。
3. 检查器直接打开操作库，最上面是「Safari 常用」快捷键。

空的应用设置在运行时视为不存在（显示全局圆环），所以加了应用但还没配置时不会打断现有使用。

### 2.4 操作库的变化

- 应用范围、未搜索时：推荐区换成「<应用名> 常用」，列出该应用尚未加入的常用快捷键（最多 5 个，带按键胶囊），下面仍是全部类型卡片。
- 「发送快捷键」类型里：先是「<应用名> 常用」，再是「常用组合键」；录制区不变。
- 搜索同时覆盖该应用的常用快捷键。
- 常用快捷键表是内置的静态表（`RingAppShortcutCatalog`，首批覆盖 Safari、Chrome、Xcode、VS Code、Figma、Slack、Finder、Notion 等常见应用），没有条目的应用只显示「常用组合键」。

### 2.5 删除、停用与撤销

- 删除应用设置不弹确认，进入撤销栈，撤销条显示「已删除 Safari 的设置 · 撤销」。删除后回到「全局」。
- 「用全局操作替换」会覆盖当前应用的操作，同样可撤销。
- 停用开关不进入撤销栈（开关本身可逆），toast 提示「已停用，Safari 中显示全局圆环」。
- 撤销栈在各范围之间共用（最多 20 步），撤销会切回发生改动的那个范围。

## 3. 边界情况

| 情况 | 处理 |
|---|---|
| 应用已卸载 | 标签带黄点；信息栏显示「找不到这个应用」；可以编辑或删除。运行时永远匹配不到，不影响任何东西 |
| 应用设置为 0 个操作 | 运行时视为未设置；设置页显示空状态（见 2.3） |
| 全局为 0 个、应用有操作 | 运行时只显示应用圆环，中心不能切换（没有页码点） |
| 同一应用多个窗口 / 多个进程 | 按 bundle id 匹配，不区分窗口 |
| 网页、文档等更细粒度 | 不在本期范围 |
| 应用数量 | 不设上限；标签栏横向滚动，选中项自动滚入可视区 |
| 录音中 | 圆环不响应触发键（现状） |
| 应用圆环里放「打开应用」指向自身 | 允许，执行时等同激活 |
| 全局操作被删除 | 不影响应用设置（应用设置是独立副本，不引用全局） |

## 4. 数据与实现映射

存储仍是 `ring.configuration.json`，向后兼容：

```swift
struct RingAppProfile: Codable, Equatable, Identifiable, Sendable {
    var id: UUID
    var bundleIdentifier: String
    /// Shown when the app is not installed any more.
    var appName: String
    var isEnabled = true
    var actions: [RingAction]           // same 8-action limit, lossy decoding like the global list
}

struct RingConfiguration {
    var actions: [RingAction]           // global, unchanged
    var appProfiles: [RingAppProfile] = []   // decodeIfPresent ?? []
    /// The profile the ring opens with for this app, if any: enabled and not empty.
    func profile(forBundleIdentifier id: String?) -> RingAppProfile?
}
```

| 模块 | 改动 |
|---|---|
| `RingConfiguration` | 新增 `appProfiles`、`profile(forBundleIdentifier:)`；`isUsable` 改为全局或任一可用应用设置有操作；旧文件缺字段时为空数组 |
| `RingController` | `pressBegan` 在取得 `previousApplication` 后解析应用设置，把「主组 + 备选组 + 中心样式」交给菜单；`select(id)` 在当前组里查找 |
| `RingMenuPresenting` / `OpieRingMenu` | `configure(primary:alternate:center:)`；新增 `onCenterClick` |
| `Packages/OpieMenu` | `RadialMenuView`：中心点击（半径 48pt）在有备选组时切换而不是 `onClose`；中心可绘制图标 + 标题 + 页码点；切换动画；`Tab` 键 |
| `RingSettingsModel` | 当前范围 `scope`（全局 / 某个 profile id）；现有 `insert / edit / replace / move / delete` 作用于当前范围；新增 `addProfile`、`removeProfile`、`setProfileEnabled`、`copyGlobal(into:)`；撤销快照包含全部范围 |
| `RingSettingsView` | 范围标签栏、范围信息栏、添加应用选择器；`RingStudioCanvas` 支持中心点击预览 |
| `RingActionLibrary` | 接收当前应用的 bundle id，提供「<应用名> 常用」分组（`RingAppShortcutCatalog`） |
| 本地化 | 新增 `ring.scope.*`、`ring.profile.*`、`ring.center.switchTo*` 等文案（en / zh-Hans / zh-Hant / ja / ko） |

测试重点：`profile(forBundleIdentifier:)` 的各分支；旧配置文件解码；`RingController` 打开时的选组、中心点击切换、执行时 id 查找；设置模型的范围切换与跨范围撤销；`RadialMenuView` 中心点击在有 / 无备选组时的行为。

## 5. 待确认

1. **切换后是否记住**：本稿每次从应用圆环开始。若希望「记住上次的页」，可做成全局开关，默认关闭。
2. **中心切换是否也用于没有应用设置的场景**（例如固定的「第二页」）：本稿不做，避免改变现有「点中心关闭」的习惯。
3. **外观是否按应用区分**（例如每个应用不同的中心文字）：本稿不做，中心固定显示应用图标和名称。
