Meet Liquid Glass

Apple Developer · Design

Liquid Glass is a new material that brings a sense of depth and vitality to controls and navigation. It adapts to the content beneath it, so controls stay legible without hiding what matters.

Use it sparingly: a good interface keeps the focus on content, and lets the material recede until it is needed.

// Adapts to the content beneath it, so controls stay legible.
struct GlassCard: View {
    var body: some View {
        content
            .glassEffect(.regular, in: .rect(cornerRadius: 16))
    }
}

1 · 一块玻璃，没有框中框

  • 改版前有 8 个带描边的容器：原文框、两个语言下拉框、蓝色描边的结果卡、每个服务各一个框，再加灰底提示栏。现在只剩面板本身这一层玻璃。
  • 分组靠留白和 1px 发丝线；选中项是 accent 浅色底，不再用 1.5pt 蓝框。
  • 按钮全部无边框、悬停才出现底色，符合 Liquid Glass「控件不叠玻璃」的规则。

2 · 语言对就是标题

  • 「翻译」标题和两条全宽下拉合并成标题栏里的 英语 ⇄ 简体中文，省下一整行（约 50pt）。
  • 点开是带搜索的语言列表，「最近使用」排在前面；⇥ 仍然轮换目标语言。
  • 入口（划词 / 输入 / 截图）缩成一个小标签；设置收进 ⋯ 菜单，标题栏右侧只剩 3 个图标。

3 · 可扫读的单词卡

  • 词头 26pt，简明释义紧跟其后用 accent 色，不再单独重复一行「好」。
  • 词性列固定 38pt 右对齐，修复 adv. 被挤成两行；变形、例句、近义词用统一的左侧标签列。
  • 例句里的关键词高亮渲染，修复译文直接显示 **好** 的问题。
  • 4 个带快捷键的大按钮改成标题行的 ☆ 收藏、↻ 重新生成、复制图标；快捷键在提示和 ? 面板里。
  • 近义词可点击，直接查这个词。
