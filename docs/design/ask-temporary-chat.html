随便问 · 临时对话（不进入对话历史）

临时对话是对话存储位置的第三个选项，和「云端同步」「仅存本机」并列。它不进入任何历史列表，不读取也不更新记忆，离开这段对话或退出应用时丢弃。临时对话可以使用全部模型。界面上用青色和虚线描边区分（虚线表示“不保存”）。
下面的窗口可以直接操作：从 ✎ 旁的 ⌄ 菜单或输入框左下角的存储图标开始一段临时对话，发几条消息后切到别的对话看看会发生什么。工具条可以切换到 ⌥Space 启动器 场景、切换登录状态和明暗主题。

实现映射

  • AskDraft.storesLocally 改为 storage: .cloud / .local / .temporary，复用 AskStorageButton 和 AskLocalModeCard。
  • 用自己的模型：使用 AskLocalEngine(store: .inMemory)，不写 AskLocal/*.json。
  • 用云端模型：首条 send 带上 temporary: true；服务端为 ask_conversations 增加 expires_at，List 时过滤，结束时 DELETE。
  • 不走 AskConversationCache、AskLauncherInputHistoryStore 和 AskMemoryProvider。
