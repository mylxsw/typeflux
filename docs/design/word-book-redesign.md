# 单词本改版与 dict 关键字 设计方案

> 状态：设计稿，待确认后开发（GUL-237 第三轮）。可交互设计稿：`docs/design/word-book-redesign.html`，截图见 `docs/design/word-book-redesign/`。前置：单词本已上线（#342–#344，`docs/design/translation-word-book.md`）。

## 0. 一页结论

1. **`dict` 关键字**：启动器关键字「翻译」一组新增 `dict`、`词典`。只输入关键字 → ↩ 打开单词本（下面列出最近查过的词，↓ 选中可直接打开到那个词）；`dict 词` → 本机先预览一行译文，↩ **打开单词本并在窗口里查这个词**（AI 单词卡在窗口里生成并自动记入）。
2. **单词本窗口改用随便问工作区的 Liquid Glass 风格**：隐藏标题栏、悬浮玻璃侧栏、环境光晕、顶部玻璃查词栏、底部玻璃操作条。
3. **单词本自己能查词**：顶部查词栏 `⌘L` 随时输入，打字时本机预览，↩ 生成 AI 单词卡；已有卡片的词直接打开，不请求模型。
4. **详情更好读、更好用**：大号词头、可朗读的音标胶囊、按词性分组的释义（点一条复制）、可朗读的例句、**可点的近义词 / 词形（点了就查）**、一行查词记录。
5. **分 2 个 PR**：P1 `dict` 关键字 + 窗口内查词（不改外观）；P2 Liquid Glass 改版。

## 1. dict 关键字

| 输入 | 显示 | ↩ |
|------|------|---|
| `dict` | 「打开单词本」行 + 最近 4 个词 | 打开单词本；选中某个词时打开到该词 |
| `dict` + 选中一个词 | 同上，第一行为「在单词本中查『选中的词』」 | 打开单词本并查这个词 |
| `dict serendipity`（已有卡片） | 卡片预览，来源「来自单词本」，「查过 N 次」 | 打开单词本到这个词（不请求模型） |
| `dict gregarious`（新词） | 本机一行译文预览，不发送任何内容 | 打开单词本并在窗口里生成 AI 单词卡 |

- 实现：不新增插件。翻译插件的关键字新增选项 `action=wordbook`（与已有的 `target` 选项同一机制），`dict`、`词典` 作为默认关键字加入翻译插件的 `defaultKeywords`；已保存关键字的老用户通过现有的「新插件默认关键字补齐」逻辑自动获得（`AskPluginRegistry.keywords(saved:known:)` 需要按关键字而非插件判断「新增」，见 §4）。
- 设置 · 启动器 · 关键字：编辑翻译关键字时多一个「动作」选项：翻译（默认）/ 打开单词本。
- `AskPluginAction.Kind.openWordBook` 增加可选的 `lookup: String?`：窗口打开后在查词栏填入并执行查词。

## 2. 窗口布局

```
┌──────────────┬──────────────────────────────────────────────────┐
│ ● ● ●        │            [ 🔍 查一个词…   ⌘L │ 英→中 ⇄ ]            │  ← 玻璃查词栏
│ 资料库        ├──────────────────┬───────────────────────────────┤
│  全部     8   │ 全部 8 个词  ⇅最近 │ 英语→简体中文 · 第3次查 · AI 卡   │
│  ★ 收藏   4   │ [过滤 ⌘F]        │ serendipity            [★已收藏] │
│  今天     2   │ 今天              │ (英 /…/ 🔊) (美 /…/ 🔊)          │
│  本周     7   │  serendipity  ★×3 │ ┌ n. 机缘巧合 · 意外发现…  ┐       │
│ 语言          │  resilient 本机   │ 例句（可朗读）                    │
│  英→中    7   │ 昨天 …            │ 近义词与词形 · 点一下就查          │
│  中→英    1   │                   │ 查词记录：共3次 首次… 最近…        │
│ ───────────  │                   │                                 │
│ 3 天连续查词  │                   │   (复制释义 朗读 问AI 重新生成 删除) │ ← 玻璃操作条
│ ▂▅▇▂ 本周    │                   │                                 │
│ 仅存在本机 ⤴ ⚙│                   │                                 │
└──────────────┴──────────────────┴───────────────────────────────┘
```

- **材质**：复用 `AskGlass`（macOS 26 Liquid Glass、13–15 HUD 毛玻璃、「减少透明度」时不透明）。侧栏、查词栏、操作条、弹出菜单都是玻璃；列表与详情直接放在窗口底色上，保证文字可读。
- **尺寸**：默认 1120×720，最小 900×560；窄于 980 时侧栏收起成图标列（与工作区一致）。
- **侧栏**：资料库（全部 / 收藏 / 今天 / 本周）、语言方向（有记录才出现），每项带数量；底部连续查词天数 + 本周七天柱条（轻量激励，不做打卡提醒）；导出、记录设置放在这里的小按钮里。
- **列表**：14pt 词头 + 音标 + 一行释义；查过多次显示 ×N；☆ 悬停出现，已收藏常显；按天分组（按最近排序时）；顶部过滤（⌘F）与排序菜单。
- **详情**：38pt 词头；音标胶囊内置朗读（英 / 美音）；收藏为醒目的星形按钮；释义卡片按词性分行，点一条复制；例句卡片带朗读；近义词与词形胶囊点击即在单词本中查；底部一行查词记录。本机译文的词显示「生成 AI 单词卡」。
- **查词状态**：打字时查词栏下方出现一行本机预览（已在单词本里的词提示「↩ 打开」）；↩ 后详情显示骨架屏与「正在请 {模型} 写单词卡…」；完成后标「新词 · 已记入今天」或「第 N 次查」，列表同步高亮。
- **反馈**：复制、收藏、删除用底部玻璃提示条，删除带撤销；重新生成前确认会发送到哪个模型。
- **空状态**：图标 + 「单词本还是空的」+ 三条上手提示（⌘L 查词、⌥Space 输入 `dict 词`、⌘S 收藏）。

## 3. 键盘

| 键 | 行为 |
|----|------|
| ⌘L | 聚焦查词栏 |
| ↩（查词栏） | 查词（有卡片则直接打开） |
| ⇥（查词栏） | 切换翻译方向 |
| esc | 清空查词栏 → 失焦 → 关闭窗口 |
| ⌘F | 聚焦列表过滤 |
| ↑ / ↓ | 在列表中移动 |
| ⌘S | 收藏 / 取消 |
| ⌘C | 复制第一条释义（焦点不在输入框时） |
| ⌫ | 删除（可撤销）；⌘Z 撤销 |
