启动器 · 右侧预览栏（Preview Pane）设计稿

有搜索结果时，启动器分成两栏：左栏是结果列表，右栏是高亮结果的详情（计算结果与各种写法、应用信息、文件内容、文件夹内容、关键词说明、工作流步骤、浏览器标签）。输入框为空时仍是现在的单栏首页，没有结果时仍是“回车问 AI”。 下方是可操作的原型：可以直接打字，也可以用 ↑↓ / ⌘1–9 / → / ⌥1–9 / ⌘C / Esc；按住 ⌘ 显示序号，按住 ⌥ 显示复制快捷键。

布局规则

  • 两栏只在有结果时出现；首页、关键词插件会话、无结果三种状态保持现在的单栏。
  • 启动器宽度从 700pt 调到 780pt，空输入时也是 780pt，所以第一次出结果时只往下展开、不横向跳。
  • 结果区高度固定 432pt：高亮切换时右栏内容高度不同，固定高度可以避免窗口跟着跳；内容超出时右栏自己滚动。
  • 动作条在右栏底部，最多 5 个 + “更多”，和 → 面板用同一份 AskQuickAction 列表。
  • 设置里加“显示预览栏”开关（默认开）；关掉就回到现在的单栏样式（点工具栏“预览栏：关”可以对比）。
