启动器 · 右侧预览 设计稿 v2

按 v1 的评审意见重做：① 外观逐项对齐现在的启动器（688pt 卡片、16pt 圆角、58pt 输入行、底部 48pt 玻璃托盘里的 ＋ / 本机存储 / 模型 / 权限 / 截图 / 记忆）；② 左栏 400pt 搜索结果为主，右栏 288pt 预览为辅，卡片宽度不变；③ 预览栏里不放工具栏，操作仍走底部提示 + → 操作面板，只用系统里已有的快捷键，并把提示改成“文字 + 键帽”的样式。
可以直接打字；↑↓ 移动，按住 ⌘ 显示序号，→ 打开操作面板，Esc 逐层退出。

快捷键提示：现状 → 新样式

现状↩ 打开 · → 更多操作 · ⌘↩ 问 AI 新样式打开↩更多操作→问 AI⌘↩
  • 文字在前、键在后：先读到“做什么”，键帽只是辅助；键帽沿用 keycapSurface（深色白 8%，浅色白底加 0.5pt 描边），高 16pt、圆角 4pt，和 ⌘ 数字角标是同一种视觉语言。
  • 组之间用 10pt 间距分开，不再用“·”。地方不够时仍按 AskLauncherContext.hintTiers 从后往前去掉。
  • 不加新快捷键：提示内容就是现有的 ask.quick.hint.* 文案，只换样式；→ 面板里的快捷键（⌥↩、⌘R、⌘Y、⇧⌘C、⌥⌘C、⇧⌘↩）也是现有的 AskQuickAction.shortcut，同样改用键帽。

不同类型的文件，右栏怎么展示

类型预览区信息（按顺序）
文本 / 代码
txt md json strings swift…		前 9 行等宽文本（以填满预览区、信息区仍可见为准），超宽截断不换行；只区分注释、键、字符串三种颜色；Markdown 只把标题加粗。底部写“共 N 行”。种类 · 大小 · 行数 · 修改 · 位置
图片
png jpg heic gif webp svg		Quick Look 缩略图按比例放进 16:10 区域，透明部分显示棋盘格。种类 · 尺寸 · 大小 · 修改 · 位置
PDF第一页缩略图，灰底居中。种类 · 页数 · 大小 · 修改 · 位置
Office / iWork
docx xlsx pptx pages key numbers		Quick Look 缩略图（系统能生成就用）；生成不了就退回大图标。种类 · 大小 · 修改 · 位置
视频 / 音频视频：一帧缩略图 + 右下角时长；音频：大图标。种类 · 时长 · 分辨率（视频）· 大小 · 位置
文件夹前 8 个子项（文件夹在前），右侧是项数或大小。项数 · 修改 · 位置
应用大图标 + 名称 + 版本。运行状态 · 版本 · 大小 · 上次打开 · 位置
压缩包 / 安装包 / 未知大图标 + 文件名，不读内容。种类 · 大小 · 修改 · 位置
敏感文件
.env *.pem *.key id_rsa*		虚线框说明“不预览内容”，只显示信息。种类 · 大小 · 修改 · 位置
iCloud 未下载大图标 + “未下载到本机”，不触发下载。种类 · 大小 · 位置

统一规则：标题最多两行；信息区一律“左标签、右数值”，位置放最后，太长时截掉开头、保留最后几级目录（同名文件靠这里区分，左栏的目录也是同样的截法）。读内容、生成缩略图都在后台做（80ms 去抖，切走就取消），还没读完时显示骨架条。
