启动器 · 文件预览窗口 设计稿 v3

新思路：启动器保持现状，一点不改。用 ↑↓ 或鼠标停在一个能预览的文件上时，启动器右侧出现一个独立的预览窗口，高度和启动器一致；停在应用、文件夹、计算或不支持的文件上时，窗口不出现，已出现的会收起。 可以直接打字，用 ↑↓ 或鼠标悬停切换。工具栏可以切换：慢动作（看清动效）、减弱动态效果、窄屏（右侧放不下时放左侧）、深浅色。

高亮项预览窗口
能预览的文件停留 120ms 后开始加载；内容好了就滑出，150ms 内没好就先带着骨架条滑出，不出现空窗口

改输入、结果变化按新的高亮项重新判断；没有结果立即收起
启动器高度变化和启动器用同一个弹簧动画（AskLauncherHeightAnimator）一起改高度，顶边对齐
拖动启动器作为子窗口跟着移动
Esc / 打开 / 发送 / 启动器失焦和启动器一起立即消失，不单独做动画
→ 操作面板、⌘Y 快速查看操作面板打开时保持显示；⌘Y 打开系统快速查看时先收起，避免两个预览重叠

动效参数

出现 180ms透明度 0→1，从启动器一侧滑出 10pt，缩放 0.985→1（以靠近启动器的边为原点），ease-out (.2,.8,.2,1) 收起 140ms透明度 1→0，往启动器方向收回 10pt，ease-in；收起后 orderOut，窗口不销毁 切换 120ms只做内容层交叉淡入，窗口位置和大小不动 高度 弹簧跟随启动器，critically damped，无回弹 减弱动态效果系统开了“减弱动态效果”时只保留透明度变化（100ms），不位移、不缩放

位置与尺寸

  • 在启动器卡片右侧 10pt，顶边与卡片对齐，高度等于卡片高度；结果很少、启动器很矮时最低 320pt（往下多出一截），否则 PDF、图片会小到看不清。
  • 宽度优先 380pt，右侧放不下就放左侧；两侧都不足 280pt 就不显示。例如 1280pt 宽的屏幕上，启动器居中时两侧都只剩约 270pt。
  • 外观和启动器一样：玻璃材质、16pt 圆角、同样的描边和阴影；顶部是文件名和信息，中间是预览区，底部是路径和现有的 ⌘Y 提示。

性能

  • 启动器零改动：预览是另一个窗口、另一棵视图树，启动器打字和列表滚动不受影响。
  • 一个窗口反复用：第一次需要时才创建，之后只 orderFront / orderOut；它不能成为 key window，键盘焦点始终在启动器。
  • 预览窗口里不用 QLPreviewView：它每换一个文件都要重新起一次渲染，视频还会自动播放，方向键快速移动时开销大。要看完整内容仍用现有的 ⌘Y 快速查看。
  • 停留才加载：120ms 去抖；高亮一变就取消上一个请求（QLThumbnailGenerator.cancel、Task 取消、子进程读取有超时）。
  • 尺寸受控：缩略图按预览区的像素尺寸生成；文本最多读 64 KB / 200 行；视频只取一帧，音频只读前 30 秒画波形。
  • 缓存：最近 32 项、上限 64 MB，key 是路径 + 修改时间 + 大小；启动器收起 60 秒后或收到内存压力通知时清空。
  • 预取：显示第 N 项后，空闲时预取相邻两项的缩略图（只限图片和 PDF）。
  • “能不能预览”是纯函数：只看扩展名 / UTType 和文件名，不读磁盘，所以切换高亮时几乎没有开销；读不了或生成失败时再收起。
