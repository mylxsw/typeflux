要点
  • 根因：结果卡早就有 Markdown 分支（output.markdown），但 AskPromptPlugin 从没打开它。改为 markdown: true，并补上 Markdown 下的对照（⌘D）和流式自动滚动。
  • ↩ 复制 仍是 Markdown 原文；新增 ⇧⌘C 复制为富文本（HTML + RTF + 纯文本），贴进邮件 / 文档就是排好版的样子。
  • 头部右侧两个按钮：☆ 收藏 ⌘S（存进笔记本，底栏提示「⌘B 打开」）、⧉ 在窗口中打开 ⌘O。生成中也能按：⌘S 会在完成后自动收藏（半透明 ☆），⌘O 把流式输出带进窗口。
  • ⌘R 重新生成后是新内容，☆ 回到空心；旧的那条保留在笔记本里。
  • 卡内高度上限沿用 280pt，长内容卡内滚动，或 ⌘O 拿出去看。

③ 笔记本窗口（⌘B）

三栏：分类 / 列表（全文搜索 + 排序）/ 阅读与编辑。正文默认渲染，「编辑」切到 Markdown 源码 + 实时预览；标题可直接改；回车添加标签；删除带撤销；导出为带 front matter 的 .md。
