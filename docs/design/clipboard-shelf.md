# 剪贴板：底部卡片架（Shelf）

> 状态：设计稿，待确认（GUL-421）。可交互设计稿：`docs/design/clipboard-shelf.html`（浏览器直接打开；`⇧⌘V` 呼出，可切换深浅色、减少动态效果、空状态）。截图在 `docs/design/clipboard-shelf/`。

## 1. 目标

参考 Paste：剪贴板从屏幕底部滑出，每条记录是一张卡片，横向排列。现有的居中列表面板（`ClipboardPanelView`，512×560 + 预览栏）保留，新形态作为「面板样式」的一个选项。

## 2. 形态

| 项 | 规格 |
|----|------|
| 位置 | 鼠标所在屏幕的 `visibleFrame` 底部（Dock 之上），左右和底部各留 8pt；宽度铺满，高 348pt |
| 出现 / 收起 | 自下而上滑出 0.26s（带轻微回弹），收起反向。开启「减少动态效果」时只做淡入淡出 |
| 材质 | 沿用 `AskGlassBackground` 的玻璃材质和 `AskTheme.floatingBorder`，圆角 18pt |
| 焦点 | 和现在一样是 non-activating key panel：不抢目标应用的焦点，粘贴后收起，内容插入原光标位置。点击面板外部或切换应用即收起 |

**顶栏（52pt）**：搜索框（300pt 宽，直接打字即搜索）· 分类 剪贴板 / 转写 / 片段（带数量）· 来源应用快捷筛选（剪贴板分类下显示最近出现过的应用图标，点一下只看该应用，再点取消；选中后搜索框里显示应用 chip，与现有 `ClipboardAppFilter` 一致）· 右侧 暂停记录 / 更多（清空未固定、设置）/ 设置。

**卡片轨道**：横向滚动，鼠标竖向滚轮也映射为横向滚动。分组和现在的 `ClipboardFeed.section` 一致：片段 / 已固定 / 今天 / 昨天 / 更早，组之间用竖排小标题 + 细分隔线。

**底栏（26pt）**：快捷键提示 + 条目数量。

## 3. 卡片

224×240pt，圆角 14pt。

- **头部 50pt**：背景取来源应用图标的主色（按 bundle ID 缓存，取不到时用中性灰）；左侧类型（文本 / 链接 / 代码 / 图片…）和时间，右侧来源应用图标；已固定的显示图钉。语音转写用 Typeflux 橙色渐变，片段用紫色渐变，标题是片段名，时间位置显示语音别名或「永久保留」。
- **正文**按 `ClipboardEntryKind` 渲染：

| 类型 | 卡片正文 |
|------|----------|
| 文本 / 语音 | 最多 8 行（语音 6 行 + 小波形） |
| 代码 | 等宽字体，保留缩进，不折行 |
| 链接 | 网站预览图 + 标题 + 域名（拿不到预览时只显示标题和 URL） |
| 图片 | 铺满裁切；多张图 2×2 网格，第 4 格显示 `+N` |
| PDF | 首页缩略图 |
| 视频 | 首帧 + 播放标记 + 时长 |
| 音频 | 波形 + 文件名 |
| 文件 | 最多 3 个文件（类型角标 + 文件名） |

- **底部 26pt**：字数 / 行数 / 尺寸·大小 / 页数·大小 / 时长·大小。原文件丢失时正文变淡，底部显示橙色「原文件已不存在」，粘贴时提示而不执行。
- **选中**：3pt 强调色描边 + 上浮 4pt。悬停上浮 2pt。
- 缩略图、波形、媒体信息继续用 `ClipboardThumbnailProvider` / `ClipboardMediaInfoProvider`，只请求可见卡片。

## 4. 交互

| 操作 | 键盘 | 鼠标 |
|------|------|------|
| 选择 | `←` `→`；`⌘←` `⌘→` 到首尾 | 单击 |
| 粘贴 | `↩` | 双击 |
| 粘贴为纯文本 / 文件路径 | `⌘↩` | 右键菜单 |
| 快速粘贴前 9 张 | `⌘1`–`⌘9`（按住 `⌘` 时卡片底部换成编号） | — |
| 预览 | `Space`（搜索框为空时）/ `⌘Y` | 右键 › 快速查看 |
| 编辑后粘贴 | `⌘E`，在预览浮层里编辑，`⌘↩` 粘贴，`Esc` 取消 | 右键菜单 |
| 固定 / 取消固定 | `⌘P`（选中跟随卡片移动到新分组） | 右键菜单 |
| 删除 | `⌘⌫`（搜索框为空时）；片段和批量删除先确认 | 右键菜单 |
| 切换分类 | `Tab` / `⇧Tab` | 点分类 |
| 暂停记录 | `⇧⌘P` | 顶栏按钮 |
| 收起 | `Esc`：依次关闭预览 → 清空搜索 → 收起面板 | 点面板外部 |

- **预览浮层**取代列表模式右侧的预览栏：在选中卡片正上方弹出 520pt 宽的浮层，显示完整内容和元数据（类型、来源、复制时间、大小）。
- 右键菜单的项目和顺序直接复用 `ClipboardEntryAction.available(for:)`，不新增动作。
- 与列表模式的键位差异只有方向键：列表用 `↑↓` 选择、`←→` 开关预览；卡片架用 `←→` 选择、`Space` 预览。搜索框里的光标因此不能用左右键移动，但搜索词一般很短，Paste 也是这样处理的。

## 5. 设置

设置 › 剪贴板 › 面板 新增「面板样式」：**卡片架（屏幕底部）** / **列表**。选「列表」时，现有的「面板位置」（启动器 / 屏幕中央 / 鼠标位置）才生效。

## 6. 实现落点（确认后再做）

- `ClipboardPanelStyle` 枚举 + `SettingsStore+Clipboard` 持久化。
- `ClipboardPanelPlacement` 增加 `shelfFrame(screen:)`（visibleFrame 底部、内缩 8pt）。
- 新视图 `ClipboardShelfView` / `ClipboardShelfCard`，复用 `ClipboardPanelModel`（数据、筛选、动作、确认、编辑后粘贴、片段编辑都不变）；`ClipboardPanelKeyCommand` 按样式切换方向键含义。
- `ClipboardPanelController` 按样式选择视图、frame 和出现动画。
- 卡片头部颜色：`ClipboardAppIconProvider` 增加主色提取并缓存。
