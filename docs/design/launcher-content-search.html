启动器内容搜索 · 应用 + 文件

GUL-239 设计稿。一个输入框同时搜应用、系统设置、文件和文件夹：自建文件名索引（内存查询 < 15 ms，FSEvents 增量更新），应用与文件共用一套模糊 / 拼音匹配，↩ 打开、→ 更多操作；新增「设置 · 启动器 · 搜索」页。下方第一块可以直接输入试用，设置页的改动会实时影响搜索结果。配套方案：docs/design/launcher-content-search.md。

  • 最佳匹配：短查询且第一名明确命中时单独置顶并占回车，「问 AI」移到最后；否则「问 AI」在第一位。文件的门槛比应用高（≥ 0.88 且领先第二名）。

2 · 状态一览

3 · 设置 · 启动器 · 搜索（新页面，可交互，改动会影响上方演示）

  • 常规：搜索模式（参考产品的 Hybrid / APP First / DOC First）、模糊匹配（对应 App Fuzzy Search，现在应用和文件共用）、结果数量、图标样式。
  • 应用范围：默认就是现在 AskAppIndex.defaultRoots 的 5 处；可以增删、恢复默认；「搜索系统设置」把 网络、显示器 等面板作为结果。
  • 文件范围：默认 ~。状态卡显示条目数、内存、最近更新、是否实时监控；可以重建或清除索引。快捷添加 iCloud 云盘和网盘目录。
  • 排除：按路径 / 文件类型 / 文件夹名，和参考产品一致；默认排除开发与缓存目录。修改后只重扫受影响的部分。
  • 权限：桌面、文稿、下载受 macOS 隐私保护。没有完全磁盘访问权限时，这三个目录的条目会在启动器里提示授权（演示：把右侧「索引状态」切到「未授权」）。
  • 试试：在「排除 · 文件夹名」里删掉 node_modules，再搜 readme；或在文件范围里删掉 ~，只保留 iCloud。

4 · 索引与检索

① 范围 + 排除规则
设置里的目录列表；按路径 / 类型 / 文件夹名排除；隐藏文件、包内部默认不进。
② 首次扫描
getattrlistbulk 批量读目录项（名字、类型、修改时间），后台 utility 优先级，低电量暂停；被排除的目录整个跳过。
③ 内存索引
目录树 + 连续名字缓冲 + 32 字节条目；字符掩码预筛，16K 一段并行扫描；拼音键只给含汉字的名字。50 万条 ≈ 31 MB。
④ 增量与快照
FSEvents 文件级事件（0.5 s）→ 增 / 删 / 改名；退出时写快照并记 lastEventId，下次启动加载快照后补齐离线变化，不重扫。
⑤ 聚焦（辅助）
首次建索引期间顶上文件名搜索；文件模式「搜内容」用 kMDItemTextContent。异步、防抖 150 ms、可取消。
