# 随便问：启动器默认态（Home）

> 状态：已实现（GUL-240）。代码：`AskLauncherHome`（纯函数，决定放什么）、`AskLauncherSuggestions`（视图与按键）、`AskConversationModel+LauncherHome`（取上下文、执行）、`AskKeywordUsage`（关键词使用计数）。

## 1. 为什么改

原来输入框为空时固定显示三条建议：「讲讲这一屏在做什么」「翻译我选中的文字」「读一下这个网页并总结」。这三条和用户当时在做什么无关：

- 在微信里呼出，也会出现「读一下这个网页」；
- 没选中文字时，「翻译我选中的文字」点了也没用；
- 「讲讲这一屏在做什么」是在解释功能，不是用户要做的事；
- 已有的关键词（`fy` `rw` `sum` `ex` `g`…）、工作流和历史对话都没有露出来。

## 2. 结构

默认态由三段组成，每一段都可能为空。内容全部由本地规则生成，不调用 AI，不联网：

| 段 | 内容 | 条件 |
|----|------|------|
| 针对当前 | 0–4 行动作 | 由选区和前台 App 决定，见第 3 节 |
| 继续对话 | 24 小时内的对话，按更新时间倒序，最多 1–3 条 | 有选中文本时不显示；上一段为 0 行时放 3 条，否则放 2 条 |
| 常用 / 试试关键词 | 一行关键词芯片，最多 6 个 | 用过的关键词少于 3 个时，显示教学版：`fy` `rw` `sum` `g` |

三段都为空时，默认态不占高度。面板高度随内容变化，顶边位置固定，向下伸缩。

## 3. 「针对当前」的规则

| 情况 | 行 |
|------|----|
| 选中一个词或短语（`AskWordCard.isLookup`） | 查词（`fy`）· 用它造几个例句（问 AI）· 解释这个词（`ex`） |
| 在代码编辑器 / IDE / 终端里选中（`CodingAppDetector`） | 解释这段代码（`ex`）· 检查潜在问题（问 AI）· 写单元测试（问 AI） |
| 选中其他文字 | 翻译（`fy`）· 总结要点（`sum`，仅在 ≥3 行或 ≥200 字时出现）· 润色改写（`rw`）· 解释一下（`ex`） |
| 没有选中，前台是 Safari / Chrome（`AskLocalTools.isSupportedBrowser`） | 总结这个网页（问 AI，通过浏览器工具读取页面） |
| 其他情况 | 不显示这一段 |

- 段标题会写清楚带了什么，比如「针对选中的 4 行 “前 60 个字…”」「针对当前网页 · 窗口标题」。
- 关键词行对应用户设置里的同一个关键词：关键词被关闭或改了提示词时，这一行不出现。行尾标出关键词本身，用户点多了自然就记住了。
- 关键词行回车 = 进入该关键词，并立即对选区运行（`AskPluginSession.update(runWhenPlanned: true)`）。结果出来后的按键与插件一致：↩ 复制，⌥↩ 写回原处，⌘S 收藏单词……
- 问 AI 行回车 = 以该问题新建对话，选区、来源和截图照常随问题发送。

## 4. 键盘

- ↑/↓：在各行之间移动，关键词芯片这一行算一站；←/→ 在芯片之间移动（高亮不在芯片上时，←/→ 留给输入框）。
- ↩：执行高亮项。点芯片只进入关键词并等待输入，相当于打出关键词再加一个空格。
- ⌘1…⌘9：直接执行第 n 行。
- 底栏提示跟着高亮项变化，例如「↩ 执行 · ⌘K 上下文 · esc 关闭」。
- 开始打字后切换为原有的快捷结果（计算、应用、关键词、问 AI），这部分行为不变。

## 5. 数据

- 关键词使用计数存在 `UserDefaults` 的 `ask.launcher.keywordUsage` 里，只保存在本机。每用一次加 1，每两周减半，最多保留 64 个关键词。打出关键词、点芯片、点行、工作流里的 `runKeyword` 都会计数。
- 对话列表在工作区打开前可能还是空的。启动器出现时先读本机缓存（`loadCachedHistoryIfNeeded`），不发网络请求，未登录时什么也不做，也不会报错。

## 6. 和设计稿相比的取舍

- 去掉了「就这段提问…」「看看这一屏」这类行：选区和截图本来就默认随问题发送，用户直接打字即可，这类行只会重复说明功能。
- 「查词」行回车后才查，不在列表里直接显示释义：查词可能要调用 AI，不应在呼出时就发请求。
- 「继续对话」只按时间排序：对话摘要（`ChatConversationSummary`）没有记录来源 App，无法做到「同一个 App 的对话优先」。
- 这一版没有「⌘↩ 带上当前选中继续对话」，也不读剪贴板。
