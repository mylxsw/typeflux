# 截图编辑器改版：对标参考应用的标注能力（GUL-319）

> 状态：设计稿，待确认。配套可交互设计稿：`docs/design/screenshot-editor-refresh.html`（`?s=<id>` 打开某一屏，`?solo=<id>` 只显示一屏，`?light=1` 浅色，`?nonew=1` 隐藏「新增」标记）。截图在 `docs/design/screenshot-editor-refresh/`：`compare` `rect` `color` `arrow` `line` `pen` `highlighter` `text` `counter` `callout` `mosaic` `pin` `more`，以及 `light-*`。
>
> 这一阶段只出设计，不改代码。

## 0. 一页结论

参考应用和我们的差距**不在工具数量**，而在**每个工具能调什么**：它的第二行按工具变化（箭头有 3 种头部 × 3 种路径，序号有字母和起始值，马赛克能只打文字……），我们的第二行对所有工具都一样，只有「5 个颜色 + 3 档粗细」。所以这次改版的重点是：

| | 现在 | 方案 |
|---|---|---|
| 第二行 | 所有工具相同：5 色 + 细 / 中 / 粗 | **按工具定制**的选项（见 §3），粗细、字号、圆角改成连续滑块 |
| 样式记忆 | 所有工具共用一套颜色和粗细，关掉就丢 | **每个工具记住自己的样式**，跨截图保存（荧光笔默认黄，箭头默认红） |
| 颜色 | 5 个固定色 | 一个色点 → 10 色面板 + 最近使用 + 自定义 + 从截图取色 + 不透明度；数字键 1–0 换色 |
| 新工具 | — | **直线**（L）、**标注**（C，文字框 + 指向线） |
| 马赛克 | 框选 / 涂抹；像素化 / 模糊 / 纯色 | 新增**椭圆**形状和**「仅文字」**范围：框住一片区域，只把识别到的文字打码 |
| 截图之后 | 复制、保存、取字、翻译、问 AI | 新增**贴图**（F）：把截图钉在屏幕上对照 |
| 工具栏 | 固定在选区下方，取字 / 翻译带文字 | 可以拖动；取字 / 翻译收成图标；低频动作进 ⋯ 菜单 |

**建议分 4 个 PR**：S1 样式基础（颜色面板、连续粗细、样式记忆、形状选项、直线）→ S2 箭头 / 画笔 / 荧光笔 / 文字 / 序号选项 → S3 标注工具 + 马赛克增强 → S4 贴图 + 工具栏拖动 + ⋯ 菜单。每个 PR 都能单独验收。

**这次不做**：录屏、GIF、表情贴纸、AI 擦除、背景美化 / 抠图（理由见 §5）。

## 1. 参考应用拆解

截图里的主工具栏从左到右是：矩形、椭圆、直线、箭头、画笔、荧光笔、文字、序号、标注（对话框图标）、表情、马赛克、斜线纹（推测）、魔棒（推测）、方框箭头（推测）、录屏、GIF、人像（推测）｜翻译｜⋯、图钉、取消、完成、拖动手柄。每张截图展示了一个工具被选中时的第二行。

| 工具 | 参考应用第二行（从截图读出） | 我们现在 | 方案 |
|---|---|---|---|
| 矩形 | 颜色点；描边 / 斜线填充 / 实心；实线 / 虚线；两个滑块（推测为粗细、圆角） | 颜色 + 3 档粗细 | 描边 / 半透明填充 / 实心；实线 / 虚线；粗细；圆角 |
| 椭圆 | 同矩形 | 同上 | 同矩形，无圆角 |
| 直线 | 颜色；实线 / 虚线；粗细滑块 | **没有** | 新增；实线 / 虚线；端点（无 / 圆点）；粗细 |
| 箭头 | 颜色；3 种箭头头部；3 种路径（弧线 / S 形 / 折线）；「边框」开关；粗细 | 颜色 + 3 档粗细，只有直线箭头 | 头部：线形 / 实心 / 双向；路径：直线 / 弧线 / 折线；白色描边；粗细 |
| 画笔 | 颜色；粗细；两种笔触 | 颜色 + 粗细，无平滑 | 粗细；平滑 / 原样 |
| 荧光笔 | 黄色；直线 / 自由；方头 / 圆头（推测）；粗细 | 颜色 + 粗细，只能自由涂 | 直线 / 自由；方头 / 圆头；粗细；默认黄色 |
| 文字 | 颜色；字体选择（SF Pro Display）；纯文字 / 底色 / 描边；字号 | 颜色 + 3 档字号，固定粗体系统字 | 字体；纯文字 / 底色 / 描边；连续字号 |
| 序号 | 颜色；数字 / 字母；圆形 / 带指向；文字样式；起始值步进器；大小 | 颜色 + 3 档大小，从 1 开始 | 数字 / 字母；圆形 / 气泡（带指向）；起始值；大小 |
| 标注 | 颜色；指向端（实心点 / 空心点 / 箭头 / 序号）；文字样式；字号。画布上是「文字框 + 一条线 + 端点」 | **没有** | 新增；指向端：圆点 / 箭头 / 无；样式：底色 / 描边框 / 纯文字；字号 |
| 马赛克 | 矩形 / 椭圆；**全部 / 文本**；5 种图案（像素、斜纹、模糊点、心形、旗帜）；强度滑块 | 框选 / 涂抹；像素化 / 模糊 / 纯色；弱 / 中 / 强 | 框选 / 椭圆 / 涂抹；**全部 / 仅文字**；三种效果和强度不变 |
| 表情 | 没有展示选项 | 没有 | 不做（§5） |
| 录屏 / GIF | — | 没有 | 不做（§5） |
| 魔棒、人像、斜线纹、方框箭头 | 截图没有展示选项，只能从图标推测（AI 擦除、抠图 / 背景、遮罩、长截图之类） | 我们已有滚动截图 | 不做或另立需求（§5） |
| 翻译 | 独立按钮 | 已有（带文字） | 保留，收成图标 |
| 图钉 | 贴到屏幕 | **没有** | 新增「贴图」 |
| 拖动手柄 | 工具栏可拖走 | 固定位置 | 新增 |

我们**已经领先**的地方要保留，不能为了对齐而丢掉：取字、问 AI、滚动截图 + 长图编辑、敏感信息检测、马赛克按文字高度自动加强（防止能读出来）、撤销 / 重做按钮、放大镜取色。

## 2. 现在是怎么工作的

- 工具：`ScreenshotAnnotationTool`（`rect ellipse arrow pen highlighter text counter mosaic`），单键快捷键 R O A P H T N M。
- 样式：`ScreenshotAnnotationStyle` 只有 `color`（5 个枚举值）和 `width`（`thin / medium / thick`），线宽、荧光笔宽、字号、序号直径、马赛克笔刷宽都从这 3 档查表得到。整个编辑器共用一份 `editor.style`，不持久化。
- 形状：`ScreenshotAnnotation.Kind`（`rect ellipse arrow path highlight text counter mosaic`），坐标都是显示器的点；标注只在一次截图里存在，**没有持久化**，改模型不需要迁移。
- 工具栏：`ScreenshotEditorToolbar`（SwiftUI），`mainBar` + `optionsBar`。`optionsBar` 只区分「马赛克」和「其他」两种。
- 渲染：`ScreenshotRenderer` 和 overlay 共用 `draw(_:in:)`，所见即所得；马赛克只读原图，永远压在其它标注下面。
- 文字识别：选区第一次确定时，`ScreenshotSensitiveInfoController.scan` 会用 Vision 把整块屏幕读一遍（本机），用来找敏感信息。识别结果里有每一行文字的位置，但目前只保留了命中规则的部分。

## 3. 方案

### 3.1 工具栏（截图 `compare` `more`）

- 主工具栏：矩形、椭圆、**直线**、箭头、画笔、荧光笔、文字、序号、**标注**、马赛克 ｜ 滚动截图、**贴图** ｜ 撤销、重做 ｜ 取字、翻译、问 AI ｜ 保存、**⋯** ｜ 取消、复制 ｜ **拖动手柄**。
- 多了 4 个按钮，所以取字、翻译改成只显示图标（悬停提示照旧），问 AI 保留文字，整体宽度和现在差不多（约 700 pt）。
- **⋯ 菜单**：另存为…（⇧⌘S）、复制并保存（⌥↩）、显示敏感信息面板（勾选项）、工具栏放到上方、截图设置…。
- **拖动手柄**：拖动后工具栏跟着走，这次截图里一直保持在那里；选区再变化也不会跳回去。「放到上方」是持久设置。
- 快捷键新增：L 直线、C 标注、F 贴图、1–0 换色、`[` / `]` 调粗细或字号。都是在没有输入文字时才生效，和现在的单键工具一样。

### 3.2 第二行：按工具定制，并且记住样式（截图 `rect` `color`）

- 第二行最左边是**一个色点**（马赛克没有），点开颜色面板：
  - 10 个常用色：红、橙、黄、绿、青、蓝、紫、粉、白、黑，对应数字键 1–0。
  - 最近使用（最多 5 个）、自定义（系统取色板）、从截图取色（复用框选时的放大镜，点一下取那个像素的颜色）、不透明度（20–100%）。
- 粗细、字号、圆角、序号大小改成**连续滑块**；`[` / `]` 每次 ±1。
- **每个工具一份样式**，存到设置里，下次截图还是上次的样式。默认值：荧光笔黄色、粗 18；其它红色、粗 4；文字底色样式。
- **选中已画的标注**时，第二行显示它的样式，改动直接作用于它（现在颜色、粗细已经这样做）；改选中标注**不会**改掉工具的默认样式，否则改一个标注会意外影响后面所有标注。

### 3.3 形状：矩形、椭圆、直线（截图 `rect` `line`）

- 填充：描边 / 半透明填充（28% 不透明）/ 实心。实心矩形可以用来盖住内容，比马赛克的「纯色」更顺手。
- 线型：实线 / 虚线（虚线长度跟粗细成比例）。
- 圆角：仅矩形，0–24 pt。
- 直线：按住 ⇧ 吸附到 0° / 45° / 90°（和箭头一致）；端点可选「无 / 圆点」，用来标尺寸、划分区域。

### 3.4 箭头（截图 `arrow`）

- 头部：线形（开口）、实心三角、双向。
- 路径：直线、弧线（二次贝塞尔，中间有一个控制点可拖）、折线（一个拐点，先竖后横或先横后竖，看拖动方向）。
- 白色描边：在箭头外面加一圈 3 pt 白边，深色、花哨背景上也看得清。默认打开。

### 3.5 画笔、荧光笔（截图 `pen` `highlighter`）

- 画笔「平滑」：松手后对点做简化 + Catmull-Rom 平滑，去掉手抖；「原样」保持现在的行为。默认平滑。
- 荧光笔「直线」：按下拖动画出一条直线（⇧ 锁水平），这是划重点最常见的用法；「自由」是现在的涂抹。默认直线。
- 荧光笔笔头：方头（`butt`，像真的荧光笔）/ 圆头。

### 3.6 文字（截图 `text`）

- 字体：系统、圆体、衬线、等宽四种，都是系统自带字体，不打包字体文件。
- 样式：纯文字 / 底色（色块 + 反差色文字）/ 描边（文字外加一圈颜色描边，白字）。底色和描边解决「红字压在复杂背景上看不清」的问题。
- 字号：10–64 pt 连续。拖角缩放照旧会改字号。

### 3.7 序号（截图 `counter`）

- 编号：1 2 3 / A B C（超过 Z 就停在 Z，并给出提示）。
- 形状：圆形 / 气泡。气泡是在按下后拖动，拖的方向就是尖角指的方向；直接点一下就是圆形。
- 起始值：步进器，1–99。删掉中间的序号后，后面的照旧自动重排（现在已经按文档顺序编号）。

### 3.8 标注：新工具（截图 `callout`）

- 用法：在要指的地方按下 → 拖到放文字的位置 → 松开，出现输入框，直接打字。点一下不拖，就在点击处放文字框，指向线之后再拖出来。
- 结构：指向点、文字框两部分，**各自可以拖**；指向线总是从文字框边缘中点连到指向点（选离指向点最近的一条边）。
- 指向端：圆点 / 箭头 / 无。样式：底色 / 描边框（深色底 + 彩色边）/ 纯文字。
- 双击编辑文字，和文字工具一致。

### 3.9 马赛克（截图 `mosaic`）

- 形状新增**椭圆**（适合头像）。
- **范围：全部 / 仅文字**。「仅文字」时，框住（或椭圆框住）一片区域，只在里面**识别到的文字**上打码，按钮、图标、图表、表格线保持清晰。框旁边显示「识别到 N 段文字 · 已打码」。
  - 文字位置来自敏感信息检测已经做过的那次识别：把 `scan` 的结果从「只保留命中的部分」扩展成「保留所有文字行的位置」，不需要额外再识别一次。识别还没完成时，先按「全部」打码，识别完成后自动收窄，不会出现「暂时没打码」的瞬间。
  - 一个文字都没识别到时，退回「全部」，并提示「没找到文字，已整体打码」。
  - 文字行的位置会向外扩 2 pt；按文字高度自动加强强度的规则照旧。
- 涂抹没有「仅文字」（涂到哪里就打到哪里）。
- 不做参考应用里的心形、旗帜等图案：它们是装饰，不是遮挡。

### 3.10 贴图：新功能（截图 `pin`）

- 点图钉或按 F：截图（含标注、已经打码）关掉编辑器，变成一个**置顶浮窗**，就放在原来选区的位置，可以同时贴多张。
- 浮窗：拖动移动；滚轮缩放（10–400%）；⌥ + 滚轮调透明度；双击或选中后按 esc 关闭；右键菜单：复制、保存、继续标注、鼠标穿透、关闭全部。
- 悬停时下方出现小工具条：缩放、透明度、鼠标穿透、继续标注、复制、保存、关闭。
- **鼠标穿透**打开后，浮窗不再接收鼠标（可以透过它点下面的窗口），要从菜单栏图标的「贴图」子菜单里关掉，或者按全局截图快捷键时出现的提示关掉。
- 贴图不进剪贴板。退出 Typeflux 时全部关闭，不做跨重启保留。
- 「继续标注」重新打开编辑器，只编辑这张图（复用长图编辑器的单图模式），完成后更新这个浮窗。

## 4. 数据与实现（确认设计后）

### 4.1 模型

```swift
struct ScreenshotAnnotationStyle: Equatable, Codable {
    var color: ScreenshotColor          // preset or custom sRGB, plus opacity
    var lineWidth: CGFloat = 4          // 1...16; highlighter 8...36
    var dash: Dash = .solid             // rect, ellipse, line, arrow
    var fill: Fill = .stroke            // rect, ellipse
    var cornerRadius: CGFloat = 0       // rect
    var arrowHead: ArrowHead = .filled
    var outlined = true                 // arrow white outline
    var smoothed = true                 // pen
    var highlighterMode: HighlighterMode = .straight
    var highlighterTip: HighlighterTip = .square
    var font: TextFont = .system
    var textStyle: TextStyle = .background  // text, callout
    var fontSize: CGFloat = 20
    var counterLabel: CounterLabel = .number
    var counterStart = 1
    var counterSize: CGFloat = 26
    var calloutAnchor: CalloutAnchor = .dot
}

enum Kind {
    case rect(CGRect), ellipse(CGRect)
    case line(from: CGPoint, to: CGPoint)                                  // new
    case arrow(from: CGPoint, to: CGPoint, path: ArrowPath)               // .straight / .curve(control) / .elbow(corner)
    case path([CGPoint]), highlight([CGPoint])
    case text(origin: CGPoint, String, fontSize: CGFloat)
    case counter(center: CGPoint, pointer: CGPoint?)                        // pointer = bubble tip
    case callout(anchor: CGPoint, origin: CGPoint, String, fontSize: CGFloat)  // new
    case mosaic(ScreenshotMosaic)                                           // Shape gains .ellipse(CGRect); scope .all / .text(runs: [CGRect])
}
```

- 每个标注自带完整的样式值，所以改默认样式不会影响已画的标注。不相关的字段对该工具没有意义，渲染时忽略。
- 工具默认样式：`ScreenshotToolStyles`（`[ScreenshotAnnotationTool: ScreenshotAnnotationStyle]`，Codable），存到 `SettingsStore`，JSON 键 `screenshot.toolStyles.json`；读不出来或缺字段时回到默认值。最近使用的颜色 `screenshot.recentColors.json`。
- 文字识别：`ScreenshotSensitiveInfoController` 额外保存所有文字行的位置（`textRuns`），马赛克的「仅文字」从这里取选区内的行。

## 5. 这次不做

| 功能 | 原因 |
|---|---|
| 录屏、GIF | 是另一个产品形态（录制控制条、编码、文件大小、麦克风 / 系统声音权限），工作量比这次整个改版还大，建议单独立项评估。 |
| 表情 / 贴纸 | 使用频率低，系统表情面板（⌃⌘Space）在文字工具里已经可以输入表情。 |
| AI 擦除（魔棒） | 需要 inpainting 模型，本机效果不稳定，走云端又涉及把截图发出去，隐私上要单独设计。 |
| 抠图 / 背景美化（人像图标） | macOS 14+ 有主体抠图接口，可以做，但和标注是两件事；建议在这次之后作为「截图美化」单独设计（加背景、圆角、阴影、边距）。 |
| 马赛克装饰图案 | 见 §3.9。 |

## 6. 待确认

1. **范围和顺序**：是否同意 S1–S4 四步、这个顺序？如果只想先做一部分，建议先做 S1 + S3（样式基础 + 标注 + 仅文字马赛克），这是最影响日常使用的部分。
2. **取字、翻译收成图标**：会让这两个入口不那么显眼。另一种做法是保留文字，把撤销 / 重做收进 ⋯（参考应用就是这样），这样主栏会更宽。建议收成图标。
3. **贴图的「鼠标穿透」**：关掉的入口放在菜单栏图标里，是否可以接受？
4. **样式持久化**：每个工具的样式跨截图保存，是否需要在 ⋯ 里加一个「恢复默认样式」？建议加。
5. **录屏 / GIF、截图美化**：是否需要另开需求排期？
