让 Typeflux 看起来就是一个 Mac 原生应用

两种形态对应 Typeflux 实际运行的两代系统：传统 = macOS 15 Sequoia 原生外观（也是 macOS 13–15 用户看到的样子），Liquid Glass = macOS 26 Tahoe 原生外观。所有尺寸、圆角、材质都以这两代系统自带应用（访达、备忘录、信息、系统设置、聚焦）为准，不再自创风格。右上角可以切换形态、外观，以及跟随系统的强调色。

五条原则

玻璃只用在导航层按 HIG 的要求，Liquid Glass 只用于浮在内容之上的那一层：工具栏、侧栏、菜单、弹出框、浮动面板、弹窗。内容层使用实底和标准控件，保证可读性。
优先用系统控件，不要自己画按钮、弹出菜单、开关、分段、表单、表格、工具栏搜索都直接用 SwiftUI/AppKit 原生控件。在 macOS 26 上它们会自动呈现 Tahoe 外观，在 13–15 上自动呈现 Sequoia 外观。只有聚焦式浮动面板和 HUD 这类系统里没有现成控件的界面才自己绘制。
系统语义色与文字样式颜色使用 labelColor、separatorColor 等语义色，强调色跟随用户在“系统设置”里的选择。字号直接用 .body、.headline 等系统文字样式，不再写数字字号。
标题放在工具栏和访达、系统设置一样，页面标题显示在窗口工具栏里，内容区不再放 22pt 大标题和副标题。
圆角同心窗口 26 → 侧栏内缩 8 → 侧栏 18 → 行内缩 8 → 行 10。所有嵌套形状都满足“内层圆角 = 外层圆角 − 间距”，这是 Tahoe 观感的关键。

“传统”形态在 macOS 26 上的含义

原生控件的形状由系统决定：在 macOS 26 上，按钮和弹出按钮总是 Tahoe 的形状，应用无法强制改回 Sequoia 的样子。因此“传统”在 macOS 26 上的含义是关闭玻璃材质：侧栏、工具栏、菜单和面板都使用实底，相当于 macOS 26.1 系统设置里的“着色（Tinted）”外观。在 macOS 13–15 上，两种形态都会以 Sequoia 的外观呈现，区别只在于浮动面板是否半透明。设计稿里的“传统”展示的是 Sequoia 外观，作为两种形态在旧系统上的基线。

迁移顺序

  • 阶段 1：窗口骨架（约 1 周）。设置窗口改用 NavigationSplitView + 工具栏标题 + 工具栏搜索，删除内容区的大标题。这一步改动最小，但对“原生感”的提升最大。
  • 阶段 2：设置页表单化（约 2 周）。各个设置页改为 Form(.grouped)，使用原生的弹出按钮、开关和分段控件；词库和历史改为 Table。
  • 阶段 3：资料库窗口。笔记、单词本、随便问统一使用模板 B。
  • 阶段 4：浮动面板。剪贴板、启动器、⌘K 统一为聚焦式面板。
  • 测试：每个阶段都沿用 AskConversationVisualTests 的渲染方式，输出“macOS 版本 × 形态 × 浅色/深色”的截图，作为对比基线。
  • 防止回退：用 SwiftLint 禁止 .font(.system(size:、字面量 cornerRadius、NSColor(calibrated…)，以当前数量为基线，只允许减少。
  • 删除：ModelVisualStyle、AskWordBookStyle、AskNotesStyle、AskWorkflowEditorStyle、SystemMonitorTheme、OnboardingProviderStyle。StudioTheme 最终只保留品牌色和少数布局常量。
