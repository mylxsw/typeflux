交互要点

  • 关键字：sys，别名 about / 本机 / 配置（可在设置中改）。sys + 空格直接进入并开始搜索字段。
  • 定位：top 看「此刻在发生什么」（实时占用），sys 看「这台机器是什么」（静态配置）。两者互相跳转：存储 / 内存 / 电池分区里的「实时占用 →」直接打开 top 并聚焦对应指标；top 状态栏的机型点击回到 sys。
  • 键盘：⌘1–⌘8 切分区，⇥ 下一分区，↑↓ 选行，↩ / ⌘C 复制该行的值，⌘⇧C 复制完整报告，⌘↩ 带上配置问 AI，⌘O 打开 macOS「系统信息」，按住 ⌥ 临时显示敏感值，esc 逐层退出（清空搜索 → 回概览 → 退出关键字）。
  • 复制优先：每一行都能一键复制「值」；复制报告默认不含序列号、MAC、公网 IP、主机名，适合直接贴到 issue / 工单里。
  • 问 AI：概览底部给出 2–3 个与本机相关的问题（例如「能流畅跑哪个本地语音模型」），发送时附带脱敏后的配置摘要。

边界与降级

  • 台式机 / 无电池：电池分区整项隐藏，⌘ 数字顺延（点右上角「台式机」查看）。
  • Intel Mac：处理器显示型号与基础频率，隐藏「性能核 / 能效核」与神经网络引擎行。
  • Wi‑Fi 名称：macOS 14+ 读取 SSID 需要定位权限；未授权时只显示「需要定位权限」和「去授权」，其余网络信息照常显示。
  • 公网 IP：唯一需要联网的字段，默认点击才查询（设置可改为自动 / 从不），查询结果只缓存在内存。
  • 慢字段：显示器、电池健康、存储设备需 IOKit / system_profiler，首次打开逐项填入（骨架占位），结果本次运行内缓存 10 分钟；网络字段每次进入时刷新。
  • 搜索无结果：提示改用 AI 提问，⌘↩ 直接把关键词连同配置摘要发给随便问。
