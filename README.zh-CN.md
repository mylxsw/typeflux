## 说出来，文字就到光标处

写邮件、回消息、记灵感，按住语音快捷键说话，松开后文字就会输入到当前应用。说话时可以看到实时文字；选中已有文字，再说“精简一点”或“翻译成英文”，也能直接修改。

你可以为工作邮件、日常聊天等场景设置不同的表达方式。输入界面也能选自己习惯的位置：

## 和 Chat 一起，把想法往前推进

从启动器发起对话，带上文件、截图或选中的文字，让 AI 帮你查资料、整理内容、翻译和写作。还可以让它在你授权的文件夹里处理文件、操作应用，把回答变成实际完成的工作。

对话里有内置浏览器、历史记录和笔记，查到的资料、正在讨论的内容可以放在一起。你也能把经常做的事情保存为指令或工作流，下次用一个关键词调用。

## 按自己的习惯使用

- **快捷键与外观**：自定义入口和关键词，选择亮色、暗色及不同界面风格。
- **本地或云端**：语音识别可以在 Mac 本地离线运行，也可以使用云端服务；AI 模型可使用 Typeflux Cloud 或自己选择的服务。
- **权限由你掌握**：默认情况下，AI 修改文件、执行命令前会先征求同意。

Typeflux 应用开源免费，云端服务可能产生费用。使用远程模型时，提交的语音或文字会发送给你选择的服务商。
